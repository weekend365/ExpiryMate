# 장고야 부탁해 · 잊힌 두부 편 · 12초 제작 패키지

엔드카드를 제외한 앞 12초용 레퍼런스와 영상 생성 지시문입니다. 영상 자체는 이 패키지에서 생성하지 않았습니다.

## 레퍼런스 업로드 순서

1. `01-woman-kitchen-reference.png` — 가상의 23세 여성, 의상, 주방, 두부, 첫 장면 기준. 단일 프레임 941×1672px.
2. `02-jango-master.png` — 저장소의 승인된 장고 원본 사본. 1024×1024px.
3. `03-storyboard-reference.png` — 4컷 구성과 감정 흐름 참고. 전체 941×1672px. 첫 프레임으로 지정하지 말고 구성 참고 이미지로 사용합니다.

`video-prompt-ko.txt`의 @이미지1, @이미지2, @이미지3을 드리미나에 실제로 업로드한 이미지 참조에 연결하세요. 화면에 표시되는 참조 이름이 다르면 그 이름으로 바꿉니다. 입력 화면에서 지원하는 길이·비율 설정을 확인하고 12초·9:16을 선택합니다. 결과 길이와 대사 타이밍은 생성 후 편집에서 검수합니다. 이 패키지는 드리미나 UI의 특정 버튼이나 음성 정확도를 보장하지 않습니다.

## 생성과 합성 구분

- 이미지의 실사 인물은 생성한 가상 성인 여성입니다. 실제 인물의 사진을 사용하지 않았습니다.
- 이미지 보드의 휴대폰 화면은 연출용 이미지이며 현재 앱의 실제 UI가 아닙니다.
- 앞 12초 안의 3–6초 휴대폰 화면에 실제 앱의 촬영용 두부 등록 데이터를 합성합니다. 두부의 남은 기한이 1일인 상태로 준비해 재료명과 남은 기한이 읽히게 확대합니다.
- ‘두부 · 1일 남음’이라는 광고용 강조 문구가 필요하면 편집에서 추가합니다. 실제 UI의 문구·배치를 임의로 실제 기능처럼 생성하지 않습니다.
- 장고의 발화는 광고용 캐릭터 연출입니다. 앱의 음성 대화 기능 시연으로 설명하지 않습니다.
- 장고 얼굴이나 파츠가 생성 중 달라지면 그 부분을 원본 PNG로 교체 합성합니다. 앱용 원본과 runtime 에셋은 수정하지 않습니다.
- 대사는 여성 “먹을 게 없네… 그냥 시킬까?”, 장고 “잠깐! 두부, 내일까지야.”, 여성 “아 맞다, 두부!”, 여성 “장고야, 고마워.” 네 문장만 사용합니다.
- 생성 음성이 정확하지 않으면 동일한 대본으로 후시 녹음합니다. 표정·입 모양과 음성, 마지막 대사 종료 시점을 확인하세요.
- 12초 마지막까지 식사 장면을 유지하고 마지막 약 0.5초는 미소를 유지합니다. 사용자가 직접 만든 3초 엔드카드를 뒤에 붙입니다.
- 앞 12초에 자막을 추가한다면 8–12초 ‘잊고 있던 재료로, 오늘 한 끼.’ 한 줄을 선택적으로 합성할 수 있습니다. 기본 프롬프트는 자막 없이 생성하도록 작성했습니다.

## 품질 확인

- 두부는 처음부터 반찬통 뒤에 있고, 여성은 장고가 알려준 뒤 발견하는가?
- 실제 화면에서 두부의 남은 기한을 읽을 수 있는가?
- 장고는 휴대폰 안의 2D 캐릭터로 유지되는가?
- 같은 여성·주방·의상·두부·휴대폰이 이어지는가?
- 요리 시간 경과가 컷 편집으로 자연스럽게 읽히는가?
- 마지막 대사가 11.5초 안에 끝나고 엔드카드용 문구나 검은 화면이 자동 추가되지 않았는가?
