# 장고 마케팅 제작 기준

장고 시각 정본은 [활성 v18 MASTER](../../design/jango/style-master.json)와
[원본 32종 목록](../../design/jango/master-set.json)이며 대표는 24번이다.
신규 제작은 [캐릭터 사용 가이드](../../docs/JANGO_CHARACTER_STYLE_GUIDE.md)와
[SNS 제작 기준](../../design/jango/reference/SNS-CARTOON-GUIDE.md)을 따른다.

현재 앱용 스토어 그래픽은 `apps/mobile/assets/store`에 있으며 `store:sync`로 재현한다. 새로운 홍보 영상이나 스토어 스크린샷은 현재 앱을 기반으로 별도 제작한다.

현재 SNS 참조는 [승인 v6 최종본](./jango-sns-ep01-v19-review-v6/README.md)이다. 폴더의 v19 명칭은
당시 제작 버전이며 현행 캐릭터 MASTER는 v18이다. 승인 4컷·전체 보기·360px 보기·게시 문구,
준비·생성·검수·Library 기록을 보존한다. 과거 선택된 [v3 대표 컷](./jango-sns-ep01-direction-v3/discovery-review-r1.png)과
[역사적 v19 승인 이미지](../../design/jango/masters/v19/master-scene.png)도 별도로 보존한다.

2026-10-14 승인본·최소 이력 기준으로 구버전 중간 이미지·레이어·마스크·QA 출력·로컬 렌더러와
종료된 UI 시안 실행 파일을 정리했다. [이번 정리 기록](../../design/jango/quality/cleanup-resources-20261014.md)에
삭제 경로·원래 해시·바이트와 동일 내용의 보존 위치를 남겼다. 과거 제작의 전체 재렌더는 지원하지
않으며, 삭제된 파일을 신규 입력이나 현재 사용 가능한 출력으로 해석하지 않는다.

[이전 정리 목록](../../design/jango/quality/cleanup-master-v18.json)의 해시·삭제 이력도 유지한다.
원격 Library·게시물·스토어 자료는 변경하지 않았다. 별도 음원 출처·라이선스 기록은 유지한다.
