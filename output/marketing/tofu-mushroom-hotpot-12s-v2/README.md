# 장고야 부탁해 · 두부버섯전골 편 · 12초 v2

엔드카드를 제외한 앞 12초용 제작 패키지. 기존 두부구이 버전은 그대로 두고 새 폴더에 저장했다. 영상 파일은 아직 생성하지 않았다.

## 변경한 메시지

냉장고 재료를 어떻게 조합할지 모르는 여성이 장고의 임박 재료 기반 레시피 추천을 확인하고 두부버섯전골을 만든다.
요리의 복잡함 자체보다, 여러 재료가 추천 화면과 완성 요리에서 똑같이 보이는 것이 이번 광고의 핵심이다.
전골은 두부·표고와 팽이버섯·애호박·대파를 쓰고, 작은 아이보리 양손잡이 냄비와 맑은 호박색 국물을 모든 이미지에서 유지한다. 대파·육수·기본 양념은 집에 있는 것으로 설정했다.
촬영용 보관 재료 데이터는 두부 D-1, 버섯 D-1, 애호박 D-2로 가정했다.

## 대사와 컷

- 0–2초 / 여성: “이걸로 뭘 해 먹지?”
- 2–6초 / 장고: “두부랑 버섯, 내일까지야. 전골 어때?”
- 6–9.5초 / 레시피를 따라 손질·조리·완성. 여성 화면 밖 대사: “오, 좋다!”
- 9.5–12초 / 식탁의 여성: “장고야, 고마워.” 마지막 0.5초 미소 유지.

## 레퍼런스 7장

1. 01-woman-kitchen.png — 승인된 여성·주방·첫 프레임. 기존 파일 그대로.
2. 02-jango-master.png — 원본 장고 디자인. 기존 파일 그대로.
3. 03-phone-recipe.png — 기존 폰 구도와 민트 배색을 유지한 임박 재료 → 레시피 화면.
4. 04-ingredient-preparation.png — 두부 손질과 버섯·애호박·대파. 조리 동작 보조.
5. 05-cooking.png — 동일 여성·냄비의 국물 끼얹기 동작. 조리 동작 보조.
6. 06-hotpot-hero.png — 완성 음식·냄비·재료 모양의 기준.
7. 07-dinner-ending.png — 동일 여성의 마지막 식사와 감사 표정.

신규 5장은 Codex 내장 이미지 생성 도구로 생성했다. 여성 얼굴·옷·주방, 요리 재료와 냄비, 휴대폰 문구를 육안 확인했다.
이미지 생성은 픽셀 단위 동일성을 보장하지 않으므로, 장고는 02 원본을 최우선 참조하고 실제 영상에서 파츠가 바뀌면 원본으로 합성한다.

## “많을수록 좋은가?”에 대한 제작 판단

참조를 늘리는 목적은 서로 다른 정보를 보완하는 것이다. 이 프로젝트에서는 7장을 준비하되 첫 생성은 핵심 5장으로 시작하는 방식을 제안한다. 이 숫자는 실험으로 입증된 최적값이 아니라 이번 컷 구성에 맞춘 제작 제안이다.
같은 역할의 미세하게 다른 얼굴, 다른 음식, 오래된 두부구이 보드를 함께 넣는 것은 피한다.

첫 생성의 업로드 순서:
- @이미지1: 01-woman-kitchen.png
- @이미지2: 02-jango-master.png
- @이미지3: 03-phone-recipe.png
- @이미지4: 06-hotpot-hero.png
- @이미지5: 07-dinner-ending.png

조리 과정이 불안정하거나 동작을 더 정확히 지정하려면:

## 휴대폰 화면과 음성

03의 휴대폰 화면은 사용자가 선호한 표현을 확장한 광고용 콘셉트 화면이며 실제 출시 앱의 스크린샷이 아니다.
사용자의 실제 앱 화면을 보여주는 광고로 완성할 때는 실제 재료·레시피 화면을 같은 구도에 합성한다. 광고용 그래픽으로 사용할 때도 실제 UI 캡처라고 표시하지 않는다.
영상 생성 중 글자가 변형되면 “두부 D-1”, “버섯 D-1”, “애호박 D-2”, “두부버섯전골”을 편집에서 고정한다. 이 정보가 읽혀야 임박 재료 조합이라는 메시지가 살아난다.
장고의 말은 광고용 캐릭터 연출이며 현재 앱의 실제 음성 대화 기능을 주장하지 않는다.
한국어 대사가 어색하거나 길이가 맞지 않으면 동일한 대본으로 후시 녹음한다. 단일 12초 생성에서 컷 타이밍이 달라질 수 있으므로 편집에서 정확히 12초로 맞춘다.
완성 장면 마지막 0.5초는 엔드카드 연결 여유이며 사용자가 만든 3초 엔드카드는 별도다.
