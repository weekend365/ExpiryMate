# 장고랑 살아보니 04 — 이걸 언제 다 입력해?

사용자가 승인한 영수증 사진 등록 콘티의 **원화 검토 후보 4장**입니다. 이번 요청은 “이 콘티로 원화부터 생성해봐.”이며, 생성물 자체의 최종 채택·영상 제작·게시와 구분합니다.

- [4장 전체 보기](review/overview.jpg) · [큰 화면 보기](review/index.html)
- [1컷 — 등록 고민](source-art/scene-01-r2.png)
- [2컷 — 영수증 촬영](source-art/scene-02-r1.png)
- [3컷 — 인식 결과 확인·등록](source-art/scene-03-r2.png)
- [4컷 — 등록 완료·요거트를 기다리는 장고](source-art/scene-04-r1.png)

공식 built-in imagegen으로 새 장면 4개와 부분 보정 2회를 제작했습니다. [프롬프트](prompts), 개별 preparation/generation JSON에 실제 참조 순서·역할·SHA-256·원본 출력 경로를 남겼습니다. v18은 캐릭터 정본, 승인 v6는 장면 통합 참조, 3화 보정본은 짧은 몸통·다리와 인물 연속성 참조입니다. 기존 원본을 덮어쓰지 않았습니다.

선택 원본은 각 941×1672px RGB PNG로 도구 출력 바이트를 그대로 보존했습니다. 별도 360×640 검토본은 비율을 유지해 축소하고 픽셀 단위로 반올림했습니다. 1080×1920 최종 영상 출력은 다음 제작 단계입니다. 1컷의 요거트는 안쪽으로 옮겼고, 3컷 휴대전화 화면을 확대했습니다. 최초 1·3컷은 편집 계보와 전후 비교를 위해 보존하되 현재 선택에서는 제외합니다.

말풍선·대사·영수증 내용·앱 화면은 이후 정확한 한글 조판을 위해 비워 두었습니다. 실제 기능은 영수증 사진에서 찾은 후보를 확인·보완하고 일괄 저장하는 흐름입니다. 그림 속 재료와 영수증은 시연 예시이며, 유통기한이 자동 확정되거나 검토 없이 저장되는 연출은 하지 않습니다.

[원화 검수 기록](review/visual-review.json)과 [선택 파일](selected-artwork.json), [제작 기록](production-record.json)을 확인할 수 있습니다. 원본과 개별 360×640 화면에서 인물·소품 연속성, 몸통 비율, 손·소품 연결과 가림을 확인했습니다. 실제 앱 문구·읽는 시간·움직임·Instagram 조작 영역·음향·커버는 원화 이후 단계의 검수 항목입니다.

앱 코드·공개 API·DB·MASTER·기존 회차·Instagram 게시물은 변경하지 않았으며, 이번 요청으로 커밋이나 푸시는 수행하지 않았습니다.
