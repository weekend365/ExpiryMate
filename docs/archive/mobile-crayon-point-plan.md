# 모바일 크레파스 포인트 적용 계획안

> **2026-10-14 철회:** 사용자가 손그림 스타일을 캐릭터·배경 이미지에만 적용하도록 범위를
> 축소했다. 홈 카드 윤곽·색칠과 첫 등록·저장 완료의 추가 기호를 제거하며, 제목·말풍선·UI
> 손글씨를 포함한 확대 후보도 종료한다. 아래는 당시 계획·승인·검증 이력이며 현행 구현
> 지침이나 미완료 과제가 아니다. 현재 기준은 [디자인 시스템](../design-system.md)이다.

이 계획은 기존 앱의 v18 기반 크레파스 장식 포인트를 다룬다. 신규 장고 자체의 작화는 [v19 공통 연필 스타일](../../design/jango/style-master.json)이 우선이며, [채택 범위](../../design/jango/reference/STYLE-MASTER-ADOPTION.md)에 따라 기존 runtime·장식 교체는 별도 진행한다. 기존 화면 구성에 손그림 윤곽·색칠·작은 기호를 더한다. 첫 적용 대상은
**홈의 장고 안내 카드 바깥 면**이다. 같은 구도의 전후 화면에서 표현과 가독성을 확인한 뒤
검토된 범위에 적용한다.

현재 진행 범위는 **선택한 A안의 홈 안내 카드와 첫 등록·저장 완료 포인트의 앱 적용·검증**이다.
홈 안내 한 곳에 선택적 SVG 장식과 공유 장식 토큰을 적용했다. 실제 앱 컴포넌트의 브라우저
비교와 Android/iOS 번들 생성을 확인했으며 실제 기기 검증은 별도로 남아 있다.
2026-10-09 기존 작업을 커밋하고 후속 우선순위를 진행했다. 현재 사용되지 않는 제목 강조
막대는 보류하고, 빈 보관함의 첫 등록 안내와 등록 완료 안내에 선택적인 정적 기호를 연결했다.
후속 브라우저 22개 상태·크기 조합의 전후 비교와 전체 테스트를 확인했다. 기기 검수는 대기 중이며
[후속 기록](../../design/reviews/jango-crayon-followup-v1/README.md)에서 관리한다.
상세 표현·접근성 규칙은 [디자인 시스템](../design-system.md)의
「모바일 크레파스 포인트 적용 기준」을 따른다. 이 계획은 그 규칙을 별도로 대체하지 않는다.

## 1. 현재 기준

- 현행 runtime의 캐릭터는 [v18 원본 32종](../../design/jango/master-set.json) 파생이며 구조 대표는 24번이다. 신규 작화의 연필 스타일 정본과 구분한다.
  화면은 기존 [Mascot](../../apps/mobile/src/components/Mascot.tsx)을 사용한다.
- 홈·보관함·추천·장보기·로그인 배경은
  [배경 동기화 목록](../../apps/mobile/scripts/sync-background-assets.mjs)에 크레파스 원본으로
  연결돼 있다. 이를 유지하면서 UI 포인트의 선·색칠 결을 맞춘다.
- 홈 안내는 [HomeHero](../../apps/mobile/src/features/home/home-hero.tsx)의
  [SurfaceCard](../../apps/mobile/src/components/SurfaceCard.tsx) 안에서 기존 캐러셀과
  [MascotSpeechBubble](../../apps/mobile/src/components/MascotSpeechBubble.tsx)을 사용한다.
- 제목은 홈 전용 [HomeSectionHeader](../../apps/mobile/src/features/home/home-section-header.tsx)와
  공통 [SectionHeader](../../apps/mobile/src/components/SectionHeader.tsx)가 서로 다른 사용처를
  가진다. 한 컴포넌트를 바꿔 모든 제목에 적용됐다고 간주하지 않는다.
- 기본 UI 폰트는 [Pretendard](../../apps/mobile/src/shared/fonts.ts)다. v18 Gaegu 원본 보존과
  앱 폰트 연결은 별개이며, 첫 대표 화면에서는 현재 UI 글꼴을 유지한다.
- 2026-10-08 철회한 크레파스 말풍선과 이전 전체 개편은 후속 적용 후보에 포함하지 않는다.
  과거 캡처는 제작 이력으로 참고하고 현재 화면의 기준 캡처를 새로 확보한다.

## 2. 적용 범위와 우선순위

| 단계 | 대상과 표현 | 보존 요소 | 다음 단계 조건 |
|---|---|---|---|
| 첫 대표 화면 | 홈 장고 안내 카드의 기존 외곽선과 가장자리 일부 색칠 | 크기·여백·상태색·장고 위치·말풍선·캐러셀·행동 | 동일 상태 전후 검토와 관련 접근성 확인 |
| 후속 후보 1 | 이미 있는 제목 강조 막대·장식용 구분선의 크레파스 획 | 제목 위계·순서·글자 영역·행동 위치 | 적용할 제목과 사용처를 지정한 검토 |
| 후속 후보 2 | 첫 안내·실제 빈 화면의 기존 장고 주변 작은 기호 | 안내·첫 행동·기존 카드·화면당 주 장고 하나 | 데이터 없음과 검색 결과 없음 구분, 큰 글자 확인 |
| 후속 후보 3 | 기존 주요 작업 완료 장면의 작은 축하 기호 | 실제 결과·복귀·실행 취소·반응 중복 방지 | 서버 성공 전 노출과 실패·재시도 회귀 확인 |

각 후속 후보는 대상 화면을 정하고 같은 구도로 검토한 뒤 적용한다. 첫 카드의 검토 결과를
공통 컴포넌트 전체의 기본값으로 전파하지 않는다. 기본 입력·버튼·탭·재고 목록·기한 신호·
법적 고지, Admin, API와 서비스 정책은 이번 포인트 적용 대상에서 제외한다.

## 3. 작업 순서와 산출물

### 0단계 규칙 정리

- [x] 디자인 시스템에 적용 영역, 표현 강도, 구현·접근성 기준과 공통 카드 계약을 명시한다.
- [x] 모바일 자동 적용 규칙을 정본에 연결하고 말풍선 보존과 선택적 장식 기준을 맞춘다.
- [x] 계획안을 문서 인덱스에 연결한다.

### 1단계 현재 화면과 영향 범위 확인

- [x] 현재 커밋·합성 데이터·상태·브라우저 화면 폭·글자 배율을 기록하고 소스 기반 기준 캡처를 확보한다.
- [x] 브라우저의 카드·말풍선·글자·이미지·버튼 영역과 접근성 이름을 전후 비교한다.
- [ ] 실제 기기의 기준 캡처와 화면 읽기·초점·터치·캐러셀 상태를 확보한다.
- [x] `SurfaceCard` 사용처(홈 1곳·인사이트 6곳)와 연관 토큰의 영향 화면을 조사한다.
- [x] 과거 홈 배경 시안은 제작 이력으로 구분하고 철회한 말풍선·전체 개편은 후보에서 제외한다.

산출물은 필요한 최소 기준 캡처와 보존·변경 요소 목록이다. 기존 UI 크기를 유지한 상태에서
장식이 들어갈 여백을 확인하고, 여백이 부족한 위치에는 장식을 넣지 않는다.

### 2단계 같은 구도의 대표 시안

- [x] 홈 안내 카드에 단일 손그림 윤곽과 가장자리 색칠을 더한 A안을 만든다.
- [x] 윤곽이 더 은은하고 색칠이 없는 B안을 함께 비교하고 카드 내부·말풍선은 동일하게 유지한다.
- [x] 같은 구도와 크기의 브라우저 시안에서 선·질감, 안내·상태의 가독성을 검토한다.
- [x] A안 권장 의견·제외한 표현·홈 바깥 면만의 범위와 미검증 사항을 기록한다.
- [x] 사용자의 A안 선택과 상태 배경색에 맞춘 색 보완 요청을 기록한다.
- [x] 실제 카드 tone에 따라 윤곽·작은 색칠을 민트·앰버·코랄 계열로 함께 바꾸고 같은 구도로 비교한다.

검토용 시안은 runtime 에셋과 구분한다. 장고 원본에는 필터·재채색·변형을 적용하지 않으며,
새 장고 제작이 필요할 때는 [장고 준비·검수 절차](../../design/jango/quality/README.md)를 따른다.

### 3단계 선택적 장식 구현

- [x] `SurfaceCard`에 기본 꺼짐인 `decoration="crayon"` 옵션을 추가한다. 현재는 `hero`에만 적용한다.
- [x] 기존 `react-native-svg`로 윤곽·고정 grain·작은 획을 구현한다. 래스터 에셋은 추가하지 않는다.
- [x] 실제 카드 안쪽 크기를 측정해 경로를 재계산하고 선 굵기·모서리를 보존한다.
- [x] 필요한 장식 역할만 [공유 디자인 토큰](../../packages/shared/src/design)에 추가하고 공개 export를 확인한다. 당시 `decoration.ts`는 UI 장식 롤백으로 제거했다.
- [x] 공통 장식 레이어에서 터치·화면 읽기 제외와 큰 글자 시 작은 획 생략을 관리한다.
- [x] A안 출처·코드형 SVG·소스 해시를 구현 기록에 남긴다. 새 이미지 파일이 없어 에셋 sync·audit 추가는 해당 없음이다.
- [x] 홈 안내 한 곳에만 옵션을 켜고 내부 말풍선·상태색 면·기존 행동 계약을 유지한다.

장식 역할은 공유 토큰, SVG 경로와 렌더링은 모바일 공통 컴포넌트가 관리한다. 화면별 장식 구현, 매 렌더 난수 질감,
런타임 질감 필터를 도입하지 않는다. Gaegu 앱 연결과 새 장고 상호작용은 첫 구현에 포함하지 않는다.

### 4단계 전후 검증과 범위별 확대

- [x] 같은 합성 데이터·크기·상태에서 실제 앱 컴포넌트의 브라우저 전후 캡처를 비교한다.
- [ ] 첫 대표 화면의 완료 기준을 확인하고 미검증 항목을 남긴다.
- [ ] 후속 후보마다 화면·상태·영향 사용처를 지정한 뒤 1–4단계를 반복한다.
- [ ] 완료된 계획은 저장소 문서 규칙에 따라 아카이브로 옮기고 활성 링크를 갱신한다.

## 4. 검증과 완료 기준

문서 정리 단계는 `pnpm docs:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`로 가능한
자동 검증을 수행한다. 실제 UI 구현 단계에서는 변경에 맞는 화면 테스트·디자인 계약 검사·
layout screenshot 비교를 포함한다. 공유 토큰 변경 시 shared build·contract test를,
에셋 변경 시 해당 sync·audit를 추가한다.

첫 대표 화면은 다음 조건을 모두 검토해야 완료다.

- 기존 5개 탭, 정보 순서, 카드·장고·말풍선·행동의 배치와 접근 경로가 유지된다.
- 손그림 선과 색칠 결이 실제 앱 크기에서 보이며 글자·날짜·수량·법적 고지 뒤에는 질감이 없다.
- 상태 의미와 대비, 터치 영역, 스크롤 길이·마지막 콘텐츠 접근, 입력·포커스가 유지된다.
- 홈의 로딩·실제 빈 상태·일반 안내·기한 경고·오류·추천 처리 중·완료 안내를 같은 조건에서 확인한다.
  처리 중·실패를 축하 기호로 표현하지 않으며 캐러셀 넘김과 안내 행동이 그대로 동작한다.
- [반응형 QA](../mobile-responsive-qa.md)의 작은 화면·가로·태블릿과 기본·확대 글자 조합에서
  잘림·겹침 없이 읽고 조작할 수 있다. 장식을 먼저 줄여도 필수 정보는 남는다.
- 화면 읽기는 장식을 건너뛰고 기존 안내·행동을 전달한다. 동작 줄이기에서도 상태가 전달된다.
- 공통 컴포넌트의 장식 미사용 화면은 기존 외관·행동을 유지한다.

변경 기록에는 요청 범위·기준 커밋·보존/변경 요소·적용 사용처·전후 캡처·관련 상태·접근성·
회귀 결과를 남긴다. 미실시 검증은 이유와 함께 표시하고 자동 검사 통과를 시각 검토나
사용자 검증으로 대신하지 않는다. 임시 자료는 저장소 밖에서 만들고 필요한 최소 결과만 보존한다.

## 5. 현재 진행 상태

2026-10-09 계획안·UI 규칙과
[홈 안내 카드 A/B 시안·검토 기록](../../design/reviews/home-card-crayon-point-v1/README.md)을 만들었다.
일반·경고·임박·첫 재료·오류·처리 중·완료·로딩 및 폭 320/360/768·글자 1/1.3/2의
대표 조합을 비교했다. 사용자가 A안 방향을 선택하고 상태 배경색에 맞춘 색 보완을 요청했다.
revision 2에서 실제 `SurfaceCard` tone에 맞춰 윤곽과 작은 색칠을 함께 바꿨다. 일반은 민트,
임박은 앰버, 기한 경고·오류는 코랄이며 추천 완료도 기존 민트 상태색을 따른다.
기존 조합에 폭 320·글자 2배의 임박·기한 경고를 추가한 16개 조건의 브라우저 DOM 배치·
이름·상태색 면·스크롤 길이가 전후 일치했다. 말풍선·장고·배경·기능 UI를 보존했다.

사용자의 실제 앱 적용 요청에 따라 홈 안내의 `decoration="crayon"`을 연결했다.
[앱 적용·검증 기록](../../design/reviews/home-card-crayon-implementation-v1/README.md)에
실제 컴포넌트의 16개 조건 비교와 대표 4장, 같은 카드의 상태 변경·터치·기본 꺼짐·마스크
독립성 확인을 남긴다. 공유 기존 기능색·Admin·인사이트 6곳·말풍선·MASTER/에셋은 보존했다.
Android/iOS 모바일 번들 생성도 통과했다. 시뮬레이터 실행 앱을 이 환경에서 열 수 없었으므로
