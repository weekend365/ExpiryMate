# v1 출시 범위

| 기능 | v1 | 이후 검토 |
|---|---|---|
| 소셜 로그인 | 카카오·네이버·구글·Apple | 추가 공급자 |
| 이메일 인증 | 가입·로그인·메일 확인·재설정 | — |
| 재고 | 수동 등록·유통기한·공간 공유·영수증/냉장고 사진 일괄 등록 | 변경 이력과 실시간 동기화 |
| 스캐너 | 네이티브 빌드의 바코드·OCR | 인식률·카탈로그 고도화 |
| AI 레시피 | 추천·히스토리·즐겨찾기 | 개인화 고도화 |
| 공유 공간 | 이메일·1회용 코드·3단계 역할 | QR·전화번호·공개 링크 |
| 수익화 | 보상형 광고·쿠팡 파트너스 | 구독·추천권 판매 |

현재 수익화 정책은 [`../monetization.md`](../monetization.md), 출시 진행 상황은
[`../STATUS.md`](../STATUS.md)를 우선합니다.

사진 일괄 등록은 기본 활성화되어 있으며, AI 고지 동의 후 후보를 검토해 저장합니다.
운영 API migration과 다음 EAS 모바일 빌드가 반영된 시점부터 실제 출시 범위에 포함합니다.
