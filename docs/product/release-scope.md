# 출시 앱과 개인 플러스 업데이트 범위

| 기능 | 현재 앱·개인 플러스 업데이트 | 이후 검토 |
|---|---|---|
| 소셜 로그인 | 카카오·네이버·구글·Apple | 추가 공급자 |
| 이메일 인증 | 가입·로그인·메일 확인·재설정 | — |
| 재고 | 수동 등록·유통기한·개봉일/확인일·공간별 변경 내역·영수증/냉장고 사진 일괄 등록 | 실시간 동기화 |
| 장보기 | 공간별 목록·수량·구매 완료·보관함 등록 연결, 별도 관련 상품 탭 | 자동 구매 |
| 알림 | 당일 설정 통합·기기 연결 상태·냉장고별 묶음·수신 시간 선택 | 정밀 시각 도착 보장 |
| 스캐너 | 네이티브 빌드의 바코드·OCR | 인식률·카탈로그 고도화 |
| AI 레시피 | 추천·히스토리·즐겨찾기 | 개인화 고도화 |
| 공유 공간 | 이메일·1회용 코드·3단계 역할 | QR·전화번호·공개 링크 |
| 수익화 | 보상형 광고·쿠팡 파트너스·개인 플러스 월간/연간 구독 | 가족 플러스·일회성 추천권 판매 |

현재 수익화 정책은 [`../monetization.md`](../monetization.md), 출시 진행 상황은
[`../STATUS.md`](../STATUS.md)를 우선합니다.

사진 일괄 등록은 기본 활성화되어 있으며, AI 고지 동의 후 후보를 검토해 저장합니다.
운영 API migration과 다음 EAS 모바일 빌드가 반영된 시점부터 실제 출시 범위에 포함합니다.

개인 플러스는 월 4,900원·연 39,000원의 자동 갱신 구독이며 무료 체험은 제공하지
않습니다. 이미 출시된 앱의 업데이트로 제공하며, 실제 판매는 실호출 원가 No-Go 검증,
스토어 상품 승인, 서버 알림과 Sandbox/License QA가 모두 끝난 시점에만 활성화합니다.

## 2026-09-29 기능 반영

이 절은 저장소 구현 범위이며 운영 배포 완료를 뜻하지 않습니다. 새 모바일 빌드 전에
`20260929090000_notification_preferences_and_digests`, `20260929100000_shopping_list`,
`20260929110000_opened_inventory_and_activity` migration을 서버에 적용해야 합니다.
실제 배포는 [운영 런북](../operations/deployment.md)의 별도 검증 절차를 따릅니다.

- **알림:** 당일 선택은 한 곳에서만 바꿉니다. 기본은 냉장고별 하루 한 묶음, 한국 시간
  09:00이며 개별 알림으로 바꿀 수 있습니다. 방해 금지 시간 안의 수신 시간은 저장할 수
  없습니다. 선택 시각 이후 스케줄러가 처리하므로 정확한 분 단위 도착을 보장하지 않습니다.
  기기 권한과 서버 토큰 등록 상태를 구분하며 연결 확인이 실제 수신 성공을 뜻하지는 않습니다.
  공간별 알림 끄기와 탈퇴한 공간의 제외는 유지합니다.
- **장보기:** 기본 화면은 실제 살 것 목록입니다. 같은 냉장고의 구성원이 공유하며 최대
  200개, 동일 이름은 공백·대소문자·문자 정규화 후 중복을 막습니다. 구매 완료한 재료를
  보관함에 등록하면 목록에 연결하며 재시도·동시 등록으로 재고가 중복 생성되지 않습니다.
  구매 완료한 이름을 다시 추가하면 새 구매 대상으로 재사용합니다. 관련 상품 검색과
  제휴 고지는 별도 탭에 유지합니다. 로컬 대기열을 통한 오프라인 수정은 지원하지 않습니다.
- **개봉 후 관리:** 등록 또는 기한 수정에서 개봉일과 직접 정한 확인일을 저장합니다.
  확인일은 개봉일과 같거나 이후여야 하며 원래 포장 유통기한을 덮어쓰거나 연장하지 않습니다.
  확인일은 섭취 가능 여부를 판정하는 날짜가 아닙니다. 보관함에 함께 표시하고 기존 알림
  간격·수신 시간에 따라 알려 줍니다. 같은 날 포장 기한과 확인일이 겹쳐도 한 재료로 셉니다.
  홈의 유통기한 통계는 계속 포장 기한을 기준으로 합니다.
- **변경 내역:** 보관함·냉장고 설정·재료 메뉴에서 등록, 수정, 부분/전체 사용, 폐기를 봅니다.
  변경과 이력 저장은 같은 transaction으로 처리하며 현재 공간 구성원만 조회합니다.
  수정자, 시각, 이름·남은 양·단위·보관 위치·날짜 변화가 기록되고 자유 입력 메모나 이메일은
  이력 사본에 저장하지 않습니다. 탈퇴 계정의 작성자 표시는 익명화하고, 공간 삭제 시
  해당 이력도 삭제됩니다. 기능 적용 전 변경은 소급하지 않습니다.
- **수익화:** 가족 플러스·일회성 추천권 판매·바코드 보상 확대를 보류합니다. 개인 플러스
  중심의 기존 상품 정책을 유지하며 기존 구매 권리와 복원은 계속 지원합니다.

## 앱 평가 요청

평가 기능 적용 후 첫 실행에서 7일이 지나고 재료 소비 저장을 3회 이상 완료한 사용자에게
기본 스토어 평가창을 요청합니다. 부분 소비도 포함하며 일괄 소비는 1회로 계산합니다.
실행 취소·실패·폐기만 수행한 작업은 제외합니다. 재요청은 최소 120일 간격,
최근 365일 최대 3회이며 이전 요청 이후 소비 완료 3회가 추가로 필요합니다.

요청은 같은 로그인 세션의 소비 성공 이후 보관함이 활성화되고 실행 취소·저장·선택·시트·
키보드·재구매 안내가 없는 상태에서 화면 상호작용 종료 후 2초 뒤에 진행합니다.
요리 중에는 표시하지 않습니다. 화면 이탈·백그라운드·계정 또는 공간 전환 시 예약은 취소합니다.
사전 만족도 질문, 평가 보상, 설정 메뉴 또는 스토어 강제 이동은 추가하지 않습니다.

사용 기간과 요청 시도는 앱 설치 단위, 소비 횟수는 사용자 단위로 기기에 저장합니다.
과거 이력은 소급하지 않으며 로그아웃으로 설치 단위 제한을 초기화하지 않습니다.
평가 표시·완료 여부는 알 수 없으므로 요청 전에 시도를 저장하고 즉시 재시도하지 않습니다.
저장·네이티브 오류와 지원 불가 상태는 기존 작업에 영향을 주지 않고 건너뜁니다.

`expo-store-review` 네이티브 의존성을 포함한 새 iOS·Android 앱 빌드가 필요합니다.
실기기에서 연동을 확인하되 TestFlight 및 스토어 표시 제한으로 창이 나타나지 않을 수 있으므로
매 호출의 실제 표시를 성공 기준으로 삼지 않습니다. 이 변경만으로 빌드·배포를 실행하지 않습니다.
