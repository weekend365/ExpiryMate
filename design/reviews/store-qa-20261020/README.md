# 2026-10-20 격리 QA 중간 종료 기록

사용자의 “지금 작업까지만 마무리하고 다음에 이어서” 요청으로 검증을 중단했다.
[시나리오별 실제 결과](scenarios.json), [빌드 상태](builds-at-pause.json),
[종료 시 서버 상태](api-state-at-pause.json)를 보존한다. 미실행 항목은 통과로 처리하지 않는다.

## 완료한 변경과 검증

- CI: 깨끗한 PostgreSQL에 migration 45개를 적용하고 DB 통합 테스트 6개를 건너뜀 없이
  실행했다. 전용 명령은 DB 설정 누락·잘못된 DB·테스트 누락·skip을 실패로 처리한다.
- 홈: 폭 400 미만·글자 배율 1.3 이상인 안내 영역에만 기존 compact 밀도를 적용했다.
  Android의 1.3 배율 부동소수 오차도 확인했다. 일반 글자 화면·문구·버튼·탭·에셋·기본 글자는
  보존했다. [홈 비교와 측정](../home-compact-20261020/README.md)에 Web 216회·native 12회
  결과와 한계를 기록했다.
- Android Galaxy A34의 실제 Play 설치본 42·43으로 월간 구매·동일 계정 복원·타 계정 거부,
  공유 참여·공간 전환·탈퇴·공간장 권한 회수·초대 코드 회수를 확인했다.
- 실제 Firebase 설정 누락을 발견했다. 사용자 승인으로 기존 `jango-plz`에 Android client와
  FCM 전용 서비스 계정을 만들고 기존 EAS 앱에 등록했다. Spark 무료 요금제·Analytics 꺼짐을
  유지했다. Play 43에서 기기 연결·백그라운드 푸시 수신·탭 후 해당 보관함 이동까지 확인했다.
- 타 계정 복원 오류 안내가 두 번 뜨는 문제를 실제 기기와 화면 핸들러 테스트로 재현했다.
  복원 중 개별 오류 안내를 생략하는 최소 수정 후 성공·거부·대상 없음·신규 구매 오류 4개가
  통과했다. 수정 후 실기기 재검증은 아직 하지 않았다.
- 현재 AI 모델의 고정 80건 평가는 이미 실행했다. 합산 사용량 기준 비용은 **$0.884803**다.
  레시피 35/50 성공, 사진 30/30 생성 성공이며 의미 품질 전체 검수는 미완료다.
  [AI 결과와 표본 한계](../../../docs/operations/ai-evaluations/current-baseline-2026-10-20/README.md)를
  따른다. 비용 기준 충족이나 모델 교체 승인으로 해석하지 않는다. 추가 유료 호출은 하지 않았다.

[최종 검증 기록](validation.json): lint·typecheck·docs:check와 패키지별 최종 테스트가 통과했다.
복원 안내 수정 후 모바일 전체 615개를 다시 실행했다. 로컬 테스트 PostgreSQL은
[중지했다](local-services-cleanup.json).

## 확인 범위와 남은 항목

- 월간 갱신은 실제 Play 복원으로 기간 연장을 확인했다. QA로 실제 RTDN 알림을 보내는
  운영 연결은 만들지 않았다. 취소는 Play 표시로 확인했고, 취소 직후 서버 willRenew 반영은
  미검증이다. 만료 후 무료 전환은 확인했으나 서버 저장 기간은 마지막 Play 기간보다 이르다.
- 연간 상품 가격과 테스트 결제창은 확인했지만 구매하지 않고 닫았다. 연간 구매·pending·환불은
  미완료다. 확인한 테스트 카드 목록에 slow/pending 카드가 없었다. 상품·판매 정책을 바꾸지 않았다.
- iOS 1.4.4(56)는 실제 IPA 버전·QA API와 Apple COMPLETE/VALID/IN_BETA_TESTING을
  확인했다. iPhone 실기기 검증은 전혀 하지 않았다. 54는 출시된 1.4.3 train 때문에 거부됐던
  별도 이력이며 기다릴 대상이 아니다.
- Webhook 인증 거부 HTTP 검사와 중복·역순 mock 검사는 실제 스토어 알림 수신과 구분한다.
  전체 native 접근성·TalkBack·VoiceOver 검증도 완료로 표시하지 않는다.

## 중단·정리 상태

- [Railway QA 프로젝트 삭제](cleanup.json)를 확인했다. API·PostgreSQL은 이번 별도 QA
  프로젝트 안에만 있었고 운영 서비스·DB·워크스페이스 공통 비용 한도는 바꾸지 않았다.
- 종료 직전 [집계 사용료](railway-usage-at-stop.json)는 **$0.00590457**다. 집계 지연과 최종
  청구액·전송료·세금은 확정하지 않았으며 이 수치를 청구서 금액으로 표시하지 않는다.
- Android 44 빌드는 중단했고 공개 배포는 하지 않았다. 폰에는 Play QA 43이 남아 있다.
  [기기 복구 기록](android-device-restored.json): 알림 권한 거부·font 1.15·density 450·화면
  1080×2340·USB 화면 유지 0을 확인했고 임시 ADB 포트를 제거했다. 앱 데이터는 지우지 않았다.
- 승인된 Firebase client와 EAS FCM 전용 등록은 유지한다. 실제 private key는 저장소나 증거에
  넣지 않았고 [로컬 임시 키 사본을 정리했다](temporary-artifact-cleanup.json). 일반 production 환경의 client file 등록과
  공개 빌드는 이번 검증 범위에 포함하지 않았다.

## 다음에 재개할 순서

1. 기존 AI $5·Railway $10 예산과 최초 72시간 제한을 자동 초기화하지 말고 유효성을 확인한다.
   원래 QA 시작은 2026-10-20 15:06 KST, 72시간 시점은 2026-10-23 15:06 KST다.
2. 새 격리 API·DB를 준비하고 가상 계정만 seed한다. **기존 QA 주소는 삭제된 환경**이므로
   `store-qa`의 API·OAuth origin을 갱신한 뒤 같은 앱 식별자·서명으로 새 빌드를 만든다.
   기존 43·56을 삭제된 API에 연결해 검증을 계속하지 않는다.
3. Android에서 중복 안내 수정 재검증, 연간 실제 구매·pending 가능 경로·취소 직후 서버 상태·
   환불을 마친다. 그다음 사용자와 합의한 순서대로 iPhone을 연결해 실기기 검증한다.
4. AI 평가는 다시 결제해 실행하지 않고 보존한 출력부터 검수한다. 영수증은 인도네시아 CORD
   외식 영수증으로 한국 마트 입력의 대표성이 없고, 냉장고 13번 정답 주석에는 불확실성이 있다.
   사진 의미·수량·누락과 레시피 조리 품질의 미검수 항목을 완료하기 전 통과를 선언하지 않는다.
