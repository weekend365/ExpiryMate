홈 안내 카드 크레파스 포인트 시안

선택한 A안의 윤곽·가장자리 색칠을 상태 배경색에 맞췄습니다. 내부 말풍선·장고·글자·버튼·배경은 동일합니다.

현재 HomeScreen·HomeHero·말풍선·재고 신호 컴포넌트를 React Native Web으로 렌더링한 검토 화면입니다. 예시 냉장고 데이터만 사용하며 실제 기기 캡처·구매·저장·음성 접근성 검증은 포함하지 않습니다. 큰 글자에서는 가장자리 색칠을 생략합니다.

검토할 차이

일반 안내는 민트, 임박 안내는 앰버, 기한 경고·오류는 코랄 계열로 윤곽과 색칠을 함께 바꿉니다. 추천 완료도 현재 카드의 민트색을 따릅니다. 시안 B는 같은 색 계열에서 색칠을 생략하고 윤곽의 강도를 낮춥니다. 배경과 장고가 이미 질감을 갖고 있어 카드 안쪽은 깨끗하게 유지합니다.
