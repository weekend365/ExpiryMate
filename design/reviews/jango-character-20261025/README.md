## 결과·접근성

- 사용 기록은 되돌리기 대기와 서버 저장을 구분한다. 대기에는 check와 실행 취소, 저장 확인 뒤에만 praise.
  부분 사용은 ‘사용을 기록했어요’, 완전 소비만 ‘다 썼어요’와 장보기 행동을 제공한다.
- 같은 저장 결과의 재렌더로 반응을 재발행하지 않는다. 화면 이탈·계정·냉장고 변경 시 이전 반응을
  취소하며, 다른 로그인으로 넘어간 대기 작업은 제출하지 않는다. query invalidation은 원래 계정·공간에 한정한다.
- 주 안내 하나가 기본 안내·오류·처리 결과를 교체한다. 새 성공 토스트를 겹쳐 띄우지 않는다.
- medium 안내는 좁은 화면·중간 이상 글자에서 세로 배치, small 안내는 큰 글자에서 세로 배치한다.
  large는 항상 세로 배치한다. 장고는 contain으로 전신을 유지하고 이미지가 입력을 가로채지 않는다.
- 입력·조리 중에는 정적 안내를 사용한다. 기존 짧은 진입 모션은 동작 줄이기에서 제거하고
  메시지 변경·언마운트 시 진행 중 애니메이션을 취소한다. 상시 반복이나 대기 시간은 추가하지 않았다.
- 장식 이미지를 접근성 트리에서 제외해 말풍선과 표정을 중복 낭독하지 않게 했다.
  필터는 이름·숫자·선택 테두리로 구분하며 기존 selected 상태·행동 이름을 유지한다.
