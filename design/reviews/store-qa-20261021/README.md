확인했다. 삭제 직전 이전 QA까지 합산한 계측 사용료는 **$0.24882127**이며 최종 청구액은

34개와 `docs:check`·lint·typecheck가 통과했으며, Android 46·iOS 58에 반영했다.

공식 Play 설치 1.4.4(46)에서 미청구 월간 테스트 구독을 구매·환불한 뒤, 앱을 종료하지 않고

상태가 표시됐다. 남아 있던 구매 완료 안내를 닫고 화면을 위로 스크롤했으며, 이 안내에는

Google의 해당 주문은 REFUNDED, 구독은 EXPIRED·ACKNOWLEDGED였다.

Android 검증을 마쳐 [알림 권한·선택 플래그·글자 배율·화면 크기·밀도·USB 화면 유지](android-restored-settings.json)를

로그인 상태는 유지한다. 사용자 확인 후 실제 데스크톱 앱 재시작과 REPL 초기화도
수행했지만 시작 오류가 이어졌다. [제어 연결 진단](ios-control-diagnostic.json)에 실행 경로와

터치 입력은 여전히 간헐적으로 실패한다. 사용자가 USB Appium/XCTest 대안을 명시적으로

기존 장고 앱을 다시 설치하거나 데이터를 초기화하지 않았다. 미러링 창 크기를 원래대로

개발자 메뉴의 기존 Sandbox 계정만 로그아웃하고 새 QA 계정의 이메일·암호를 입력했으나,
‘Apple 계정 보안’ 안내가 표시돼 로그인이 완료됐다고 처리하지 않았다. 보안 안내의
‘기타 옵션’ 조회는 자동 승인 검토에서 인증 우회 가능성·구체적 승인 부재를 이유로
거부했으며 실행되지 않았다. 사용자가 기기에서 안내와 인증을 직접 처리하도록 인계했다.
사용자가 인증을 완료한 뒤 새 Sandbox 계정 메뉴를 대조했다. 보안 설정·인증 수단을
에이전트가 변경하거나 인증을 우회하지 않았다.

Apple 공식 절차에 따라 사용자의 별도 승인을 받아 **미디어 및 구입 항목만** 로그아웃하고
새 Sandbox 계정 유지·QA 앱 재실행을 확인했다. 이후 실제 스토어의 미청구 연간 구매창이
열렸고 사용자가 측면 버튼·기기 인증으로 승인했다.
[연간 구매·같은 계정 복원](ios-58-yearly-purchase-result.json)과
[통제된 타 계정 복원 거부](ios-58-single-restore-dialog-verification.json)가 통과했다.
구매자 연간 Sandbox 이용권은 활성, 멤버는 비활성이며, 복원 뒤 기존 만료일이 보존됐다.
타 계정 거부 안내를 닫고 7.054초 동안 두 번 확인해 후속 팝업이 없었다.
Sandbox 관리에서 연간 구독 취소도 확인했다. 만료 예정은 **10월 21일 17:43:18 KST**이며,
서버의 취소 갱신과 자연 만료·월간·공유·푸시는 계속 확인한다.
스토어 계정 전환 뒤 앱은 USD 가격, 실제 Sandbox 구매창은 KRW 가격을 표시한 차이가 있어
가격 일관성은 아직 통과로 처리하지 않는다. **QA 종료 후 미디어 계정 복원이 필요하다.**

QA 프로젝트는 현재 유지 중이고
[비용·원래 종료 시점 감시](qa-monitor-status.json)를 클라이언트 재시작과 독립된 로컬
프로세스로 전환했다. 실제 QA 리소스 삭제는 아직 하지 않았으며 완료로 처리하지 않는다.

[전체 검증 기록](validation-progress.json)에는 root 41개·shared 162개·API 618개와
빈 DB 통합 6개·모바일 617개의 통과 결과를 구분해 남겼다. 최초 `pnpm test`의 기존
캐릭터 재현 테스트 1건은 20초 시간 초과였고, 모바일 전체를 순차 재실행해 617개가
통과했다. 제한값·제외 목록은 변경하지 않았다. 임시 로컬 DB는 정상 종료했고 데이터를
보존했다. 사용자 작업 파일의 해시도 유지했다.

사용자와 합의한 순서대로 Android 검증을 마친 뒤 iPhone을 연결한다. 실제 스토어·기기 결과와
HTTP 검사·격리 자동 테스트는 구분한다. 모든 미실행·증거 부족 항목은 미완료로 유지한다.

새 대화에서 이어갈 때는 이 기록과 `ios-progress.json`·`current-handoff-status.json`, 저장소
규칙을 먼저 읽는다. 장고·TestFlight·관련 테스트 구독 화면을 사용하는 iPhone 미러링은
사용자가 승인했고, 가상 공간장 계정 로그인은 이미 완료했다. 설치된 빌드는 1.4.4(58)이다.
임시 계정·세션·기기 대상은 `/tmp/jango-store-qa-20261021`의 `test-accounts.json`,
`sessions.json`, `ios-target.json`에 있으며 비밀값을 출력하거나 저장소로 복사하지 않는다.
사용자는 USB Appium/XCTest 보조 앱 설치와 QA App ID·프로필 생성을 명시적으로 승인했다.
현재 미러링은 종료했고 iPhone은 잠금 해제 상태로 USB 검증한다. 보조 앱 ID는
`com.expirymate.qa.webdriveragent.xctrunner`이며 임시 경로 `usb-ui-prep/wda.py`와
`running-processes.json`에서 로컬 USB 세션과 해당 실행 프로세스를 확인한다.
진행 상태를 먼저 확인해 완료한 연간 구매·복원을 반복하지 않는다. 실제 Apple 인증이
필요하면 사용자에게 맡기며, QA 종료 후 보조 앱·로컬 제어 프로세스를 정리하고
미디어 계정 복원을 확인한다. 기존 개발 인증서·등록 기기는 삭제하지 않는다.
QA 푸시 준비를 위해 가상 공간장 알림 설정은 잠시 비활성화했고, 원래 값은 임시 경로의
`ios-push-staging-preferences.json`에 있다. 새 iOS 토큰을 확인한 뒤 복원하고 정기 스케줄러로
검증한다. Android 원래 설정은 이미 복원했으며 앱 데이터를 초기화하지 않는다. 기존 AI
유료 실측은 끝났으므로 다시 호출하지 않는다. 기기·증거가 없는 항목은 미완료로 남긴다.

QA 비용 감시는 Mac의 별도 로컬 프로세스다. 클라우드 스케줄러가 아니므로 Mac 종료나
네트워크 단절 시 원격 삭제를 보장하지 않는다. 검증 완료·중단 또는 기존 한도에 도달하면
증거와 사용료를 보존한 뒤 **QA 프로젝트 `112c819c-0cdb-4990-8650-c2939b2932e5`만**
정리하고 실제 삭제를 확인한다. 워크스페이스 공통 한도와 운영 리소스는 변경하지 않는다.
