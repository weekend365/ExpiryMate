## 주요 상태·접근성 검증

- 홈: 320/360/780 폭 × 1/1.3/2 글자 배율의 9개 조합. 가로 넘침 없음, 세로 배치의 장고·본문 겹침 없음.
- 추천: 위 9개 조합에서 근거와 추가 재료 수의 line clamp 없음. 본문 영역 높이와 스크롤 높이 일치.
- 사진: 카메라 권한 유무와 무관하게 앨범 이어가기 제공. 큰 글자·권한 거절 화면은 스크롤로 행동 도달.
  대기/준비 중 버튼 비활성, 명시적 탭으로만 진행. 동의·횟수를 다시 조회하며 실패·취소·계정/공간 변경 뒤에는 진행하지 않는다.
  분석 중 계정/공간이 바뀐 경우 이전 응답으로 새 화면의 결과를 채우지 않는다.
- 입력: 값 입력 후에도 레이블 유지. 두 입력에 접근성 이름과 공유 최소 조작 높이 적용.
- 알림: 기본 설정 수정 → 미저장 표시 → 기본 설정 저장 후 해제, 공간 스위치 → 서버 확인 후 저장됨 표시.
  오류 시 서버가 확인한 기존 상태 유지. 진행 중 계정 변경에 대한 캐시 격리 테스트 포함.
- 개인정보: 최초 조회·실패·캐시 갱신 실패에서 0건 문구를 표시하지 않음. 재시도 중 중복 행동 숨김,
  재조회 성공 후 실제 건수 표시. 오류→조회 중→8건의 fixture 전환 확인.
- 버튼·문구는 색상뿐 아니라 텍스트로 상태 전달. 공통 글꼴 배율 상한과 동작 줄이기 처리는 유지했다.

## 화면 증거와 방법

캡처는 **실제 컴포넌트를 React Native Web으로 렌더한 로컬 fixture**다. 왼쪽은 변경 전,
오른쪽은 변경 후다. 폰트는 저장소의 Pretendard, 캐릭터는 기존 runtime 파일이다.
텍스트 배율은 Native의 글꼴 배율 상한을 적용하는 어댑터로 재현했다.
카메라·안전 영역·애니메이션·라우터·네트워크는 대역이며 실제 촬영·광고·저장·삭제 요청은 보내지 않았다.
추천 카드와 사진 수정 필드는 해당 소스의 JSX/스타일을 추출해 같은 fixture 데이터로 렌더했다.
