# v18 장고의 앱 사용 포즈 확대

2026-10-15 사용자가 기존에 사용하지 않던 이모티콘을 적절한 곳에 더 배치하도록 요청했다.
기준 커밋은 `8ccaf6d`다. v18 원본 32종 중 8종을 추가해 앱 사용 포즈를 8종에서 16종으로 늘렸다.
새 작화 없이 원화 전체를 비율 유지해 파생했고, 현재 의미와 맞는 화면의 기존 캐릭터 영역만 바꿨다.

## 적용 위치

- 07 「화이팅!」 / `encourage`: 온보딩의 첫 시작 안내.
- 08 「잘했어!」 / `praise`: 재료 등록 완료 안내와 사진 등록 완료의 캐릭터.
- 09 「응!」 / `acknowledge`: AI 데이터 안내에 동의한 상태의 확인 안내.
- 10 「좋아좋아!」 / `excited`: 홈에서 추천 준비가 완료된 상태. 기한 경고의 우선순위는 유지한다.
- 18 「괜찮아!」 / `comfort`: 보관함에서 현재 필터에 맞는 결과가 없는 상태.
- 22 「맛있다!」 / `enjoy`: 조리 완료와 이후 사용량 정리 단계의 안내.
- 25 「냉장고 체크!」 / `check`: 급한 재료가 없는 홈 안내와 정리가 된 보관함 안내.
- 26 「장보기 가자!」 / `shopping`: 장보기의 상품 검색 진입 안내.

원본 번호·mood·접근성 표기는 [앱 포즈 목록](../../../apps/mobile/assets/characters/moods.json),
원본 경로·해시·가공 설정은 [파생 목록](../../jango/manifest.json)에 기록한다.
기존 8종의 매핑과 기본 포즈·아이콘·스플래시의 24번은 유지한다. 남은 16종은 중복 감정이나
현재 화면에 맞는 사용 맥락이 부족해 추가로 노출하지 않았다. 사랑·수면·피로 등의 표현을
오류나 식품 상태 안내에 임의로 연결하지 않는다.

## 보존 범위와 파생

탭·정보 순서·문구·버튼·필터·캐러셀·터치 영역·색상·글꼴·레이아웃·API·사용자 흐름은 유지한다.
오류·기한 경고의 mood와 상태색, 빈 보관함의 기존 포즈도 유지한다. 기존 파일의 원본/앱 에셋
바이트가 같은지는 [검증 기록](./verification.json)에서 확인한다.

`mascot:sync`·`mascot:build`로 새 1024px 파생과 full/small·1x/2x/3x 출력을 생성했다.
runtime은 48개에서 96개로 늘었다. runtime PNG 합계는 2,916,070 bytes 늘었다. 최종 앱의
압축·설치 용량 증가는 별도 빌드 측정이 필요하며 이 파일 합계와 동일하다고 주장하지 않는다.
기존 원본 32종과 보호 에셋 237개, 기존 앱 에셋·브랜딩·배경·스토어 이미지는 바이트를 보존했다.
원본에는 재채색·크롭·전신 재작화를 하지 않았다.

`mascot:measure`의 추가 관찰은 MASTER 목록의 기존 얼굴/입 ROI·기울기·입 모드를 그대로
사용한다. 기존 9개 관찰 결과와 20번의 입 재검토 상태는 유지한다. 새 8종은 현재 입 검사에서
통과했지만 전체 디자인 승인이나 서명된 이모티콘 출시는 아니다. 출시 서명은 생성하지 않았다.

## 화면과 검증

실제 `CrayonReviewScene`, 홈·보관함·등록 완료·장보기 컴포넌트와 상태 함수를 사용한
임시 React Native Web 전후 fixture로 검토했다. 온보딩·동의 확인·조리 완료는 기존 공통
컴포넌트에 해당 화면의 문구와 mood를 적용한 부분 검토이며 전체 화면 캡처로 주장하지 않는다.
임시 HTML·bridge·번들·의존성은 저장소 밖에 두었다.

폭 320/360/768·글자 배율 1/1.3/2의 12개 상태, 총 108개 조건에서 문구·이미지 영역·노드 배치·
버튼·상태색·스크롤 크기가 같았다. 이미지와 해당 mood의 접근성 이름만 의도적으로 달라졌다.
각 화면에 실제 이미지와 문구가 렌더링됐는지 확인한 뒤 측정했다. 글자 배율은 Web의 투영이며
네이티브 큰 글자 검증을 대신하지 않는다. 모션은 검토용으로 고정했고 safe area·계정·API 호출은
제외했다. 검토 번들에서만 Lucide의 사용하지 않는 provider export를 제외했으며 제품 의존성은 수정하지 않았다.

Android/iOS 실제 기기 전후 캡처, VoiceOver/TalkBack, 네이티브 모션·폰트 배율 검증은 미실시다.
브라우저 검수를 이들 검증의 통과로 해석하지 않는다. 스토어 빌드·업로드·배포·원격 게시와
이모티콘 출시·MASTER 교체는 수행하지 않았다.
