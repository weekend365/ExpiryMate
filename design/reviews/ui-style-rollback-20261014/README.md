# 손그림 이미지 범위 정리 · UI 장식 롤백

2026-10-14 사용자가 손그림 스타일을 캐릭터·배경 이미지에만 적용하고 UI 장식과 관련
규칙을 되돌리는 계획을 승인했다. 기준 소스는 `3f19b07`이며 `c057084`·`3d6a854`의
장식 추가분만 분리해 제거했다. 현재 기준은 [디자인 시스템](../../../docs/design-system.md)이다.

## 변경과 보존

- 홈 안내 카드의 크레파스 윤곽·색칠을 제거하고 기존 일반 테두리를 복원했다. 빈 보관함과
  등록 완료의 추가 SVG 기호도 제거했다. 캐릭터 이미지 자체에 포함된 표현은 유지한다.
- 장식 렌더러·경로·전용 토큰과 `decoration`·`mascotDecoration` 옵션을 제거했다.
  `SurfaceTone`은 일반 공유 토큰으로 옮겼으며 공개 export와 기존 tone 값은 유지했다.
- 캐릭터·배경 이미지, 5개 탭, 안내 문구·순서·장고 포즈·버튼·캐러셀, 상태색·여백·글꼴을
  유지했다. 인증·구독·글자 크기 수정, QA 앱 ID·scheme과 기존 fixture 진입점은 변경하지 않았다.
- UI 확장 규칙과 Gaegu 앱 연결 계획을 제거하고 [기존 계획](../../../docs/archive/mobile-crayon-point-plan.md)을
  아카이브로 옮겼다. 과거 승인·시안·기기 검수·manifest 해시는 보존하며 철회 사실을 별도로 표시했다.
- 공통 컴포넌트의 기본 미사용 화면은 기존 표현을 유지한다. `SurfaceCard`의 인사이트 사용처,
  일반 카드·말풍선·기능 UI에 새 스타일을 전파하지 않았다.

## 전후 검토

실제 `HomeScreen`과 공통·feature 컴포넌트를 예시 데이터로 React Native Web에 렌더링했다.
변경 전·후 번들을 별도로 고정하고 Chrome CUA로 확인했다. 기존 검토 adapter의 고정 safe
area·정지 모션·글자 배율을 사용했으며 API·계정·구매·영속 store는 번들에서 제외했다.
Web 의존성은 저장소 밖에 준비했으며 제품 의존성·lockfile은 변경하지 않았다.

홈 일반·임박·만료·빈 상태·오류·추천 처리 중·완료·로딩, 보관함 빈 상태·필터 결과 없음·
로딩·최초/새로고침 오류·일반 상태, 등록 단건/다건 완료·처리 중·오류와 화면 폭
320/360/768·글자 배율 1/1.3/2의 대표 **39개 조건**을 비교했다. 문구·글자/이미지 위치·
기존 접근성 이름·버튼 영역·상태색 면·스크롤 크기의 측정 해시가 모든 조건에서 동일했다.
장식 mask는 변경 후 0개다. 추천권 보상 안내의 순서·문구·추천 callback은 관련 테스트로 확인했다.

리터칭하지 않았다. 빈 보관함은 위 280px, 등록 완료는 위 460px에 문구·행동·callback 표시가
모두 포함된다. 홈 두 장은 780px 전체 높이를 유지한다. 픽셀 변화는 홈 카드 장식·윤곽과
장고 주변 추가 기호 영역에 한정됐고, 폭 320·글자 2배의 다건 완료 캡처는 픽셀까지 동일했다.

전후 양쪽에서 첫 재료 등록 callback 1회, 추천·추가 완료 각각 1회, 큰 글자의 스크롤 아래
추가 완료 callback 1회를 확인했다. 캐러셀은 양쪽 모두 가로 스크롤 0→246으로 다음 안내에
도달했다. 측정 조건·출처·캡처 해시·픽셀 비교·동작 결과는 [verification.json](./verification.json)에 둔다.

## 자동 검사와 이미지 보존

- 관련 모바일 테스트 63개, shared build, `pnpm docs:check`, `pnpm lint`, `pnpm typecheck` 통과.
- `pnpm test`는 장고 23·shared 162·API 589·mobile 574, 총 **1,348개 통과**다. 기존 API 6개는 skip이다.
- `pnpm jango:check`와 모바일 `backgrounds:audit`·`mascot:audit`·`branding:audit` 통과.
  브랜딩 검사의 기본 Python에는 Pillow가 없어서 기존 검증용 Python/Pillow 12.3.0으로 재실행했다.
- 에셋·폰트·v18 원본·v19 MASTER 및 레지스트리 323개 파일의 SHA-256이 변경 전과 같다.
  기존 시안 이미지와 승인·검수 manifest도 변경하지 않았다. runtime·브랜딩 이미지를 재생성하지 않았다.
- `jango:reports:refresh`로 갱신한 32개 보고서는 binding과 스타일 문서 해시만 바뀌었다.
  측정·불확실성·재검토·준비·채택·출시 내용은 모두 동일하다. 새로운 검수 승인이나 서명을 만들지 않았다.

## 검증 한계

이번 변경의 Android/iOS 실기기 전후 캡처, VoiceOver/TalkBack, 네이티브 동작 줄이기는
미실시다. 브라우저 글자 배율은 네이티브 검증을 대신하지 않는다. Web 캐러셀의 momentum-end
접근성 순번 갱신도 네이티브 검증으로 간주하지 않는다. 폭 320·글자 2배의 기존 좁은 줄바꿈은
전후 동일하며 추가 완료는 스크롤로 접근 가능하다. 스토어 빌드·업로드·출시·배포는 수행하지 않았다.
