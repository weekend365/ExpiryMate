# v20~v23 종료 제작 기록

[이력 안내](../../../emoticons/kakao-32/history/README.md)와 [목록](index.json)을 따른다. 원문 후보 97건, 준비 97건, 검수 보고서 97건을 보존했다. 준비·프롬프트·출처·해시는 원문이며 현재 승인이나 새 검증 결과가 아니다.

- [변경 전 문서·최종본 메타데이터](before)
- [현재 최종본](../../../emoticons/kakao-32/v24/README.md)
- [정리·보존·테스트 검증 기록](../../cleanup/20261020-history-verification.json)

목록의 `deduplicated`는 실제 동일 바이트를 확인할 수 있는 보존본, `relocated`는 원문 기록의 새 보관 위치, `retired`는 삭제되어 현재 바이트를 확인할 수 없는 시안이다. 고유 시안의 과거 해시를 현재 측정값으로 반환하지 않는다. 목록 해시와 조회 코드 해시가 현재 검증 기준에 포함된다. 보관 위치를 부모 계보로 해석하지 않으며 심볼릭 링크·경로 탈출·별칭 체인을 허용하지 않는다.

CLI는 `pnpm jango:history:cleanup`(목록 확인), `--apply`(복구 사본 후 적용), `--check`(무결성 검증)다. 적용 후 재실행은 검증만 수행한다. 이 버전의 새 작화·재조립·등록·출시는 차단된다. 앱 API·공유 계약·서명 조건은 변경하지 않았다.
