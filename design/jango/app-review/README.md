# v18 앱 적용 확인

2026-10-01, Pixel 3a API 33 로컬 에뮬레이터에서 확인했다. 화면은 720×1280, 320dpi, 글자 배율 1.0이다. 로그인/API 동작을 변경하거나 원격 배포하지 않았다.

- [로그인](./android-login.png): 24번 기본 장고의 모자·장갑·접시·발을 모두 표시한다.
- [온보딩](./android-onboarding.png): happy에 연결된 02번의 전체 구도를 유지한다.
- [Android 런처](./android-launcher.png): 원형 아이콘 안에 24번의 모자·접시·발 전체가 표시된다.
- [네이티브 스플래시](./android-splash.png): 24번을 88dp로 표시한다. Android 전용 288dp 캔버스 안에 배치해 OS 원형 마스크로 인한 모자·발 잘림을 해소했다.
- [밝은 배경 크기 비교](../app-review-light.png)·[어두운 배경 크기 비교](../app-review-dark.png): 8개 mood의 52/72/120px 표시. 52px에서는 미세 질감이 약해지지만 전체 구도와 표정을 유지한다.
- [브랜딩 비교](../branding-review.png): 24번에서 파생한 아이콘·스플래시·알림 실루엣.

모든 런타임 PNG와 네이티브 배율 파생물을 생성기와 대조했다. Android 디버그 빌드는 설치된 NDK 28.2.13676358을 명령행에서 지정해 오프라인으로 빌드했다. 저장소의 SDK 버전 설정은 바꾸지 않았다.

iOS 이미지 일치는 검사했지만 로컬 Xcode 라이선스가 미동의 상태여서 iOS 시뮬레이터 실행은 하지 않았다. 로그인 후 화면은 이번 시각 검증에 포함하지 않았다. [전체 검증 결과](../quality/master-adoption-validation.json)에 자동 검사·보존 해시·삭제 수·입 재검토 상태를 기록했다.
