# 장고 카카오톡 이모티콘 32종 기획안 v1

세트 가제: **밥도 마음도 챙기는 장고**

앱을 모르는 사람도 친구·연인·가족·동료와 쓰는 일상 대화 세트다. 전체를 관통하는 성격은 “밥과 일상을 다정하게 챙겨주는 친구”. 밥과 요리는 장고의 배려 방식으로 사용하고, 앱 기능 안내는 대사에 넣지 않는다.

디자인 기준: jango-idle MASTER · JANGO CHARACTER BIBLE v1 · 확정 TEST POSE v3. 이 문서는 기획안이며 새로운 이미지·애니메이션은 제작하지 않았다.

일상 대화와 직장/학교는 각각 4종, 나머지 8개 성격은 각각 3종으로 주 용도를 배정했다. 이는 중복 없는 편성 기준이며, 실제 사용 대상은 서로 겹친다. 애정 표현을 주 용도로 둔 3종도 친구·가족에게 쓸 수 있다.

요청한 관계 메시지 9종: **보고 싶어 · 사랑해 · 뭐해? · 밥 먹었어? · 잘 자 · 기다릴게 · 삐짐 · 미안해 · 안아줘**

## 제작 공통 규칙

- 외형 기준은 jango-idle MASTER와 확정 TEST POSE v3다. 얼굴 비율, 눈 중심 간격, 모자 다섯 볼륨, 문 구조, 왼쪽 손잡이·파인애플, 오른쪽 두 경첩, 민트 팔레트를 고정한다.
- 등장하는 캐릭터는 장고 한 명이다. 연인·친구·가족은 화면 밖 수신자로 설정한다. 빈자리·창밖·열린 품으로 관계를 표현하며 상대 인물이나 친구 캐릭터를 추가하지 않는다.
- 한 장갑은 둥근 주머니 하나·엄지 하나·커프스 하나다. 휴대전화·연필·거품기는 주머니와 엄지 사이로 받친다. 손가락 하트, 검지 가리키기, 다섯 손가락, 사람 주먹 마디는 사용하지 않는다.
- 목·팔·다리·모자를 늘이거나 냉장고 얼굴을 찌그러뜨리지 않는다. 앉기·눕기·달리기는 관절 회전과 가림으로 구현한다. 얼굴에 붙은 표정과 장식은 고개와 함께 이동한다.
- 각 몸 동작 설명이 정지 이모티콘의 대표 장면이다. 애니메이션은 이 장면으로 들어가고 나오는 짧은 동작으로 확장한다. 대사를 가려도 인사·거절·놀람·위로·허기 같은 의도가 먼저 읽혀야 한다.
- 대사는 한 컷에 제시된 문구 하나만 사용한다. 문자 레이어는 별도로 두고 얼굴·모자·장갑을 가리지 않는다. 앱 이름, 기능 설명, 특정 연애 호칭, 유행어에 의미를 의존하지 않는다.
- 소품은 행동을 설명하는 최소한으로 둔다. 소품에 얼굴·상표·복잡한 화면을 넣지 않는다. 냉장고 문 열기나 내부 수납 장면은 새 구조 설계가 필요하므로 이번 32종에는 넣지 않는다.
- 32종을 비교할 때 캐릭터의 기준 크기를 통일한다. 누운 자세나 넓은 동작이 들어가도록 공통 여백을 잡고, 컷마다 머리를 따로 줄여 맞추지 않는다. 좌우 설명은 관찰자 기준이며 완성 이미지를 단순 반전하지 않는다.

## 동작 중복을 피한 구분

- 좋아 / 안아줘: 좋아는 팔을 옆으로 열고 한 발을 드는 바깥 방향의 기쁨, 안아줘는 한 걸음 다가가 팔을 앞으로 여는 초대다.
- 고마워 / 미안해: 감사는 앞에 포갠 손과 나란한 발, 사과는 뒤로 모은 손과 머뭇거리는 발끝으로 구분한다.
- 보고 싶어 / 기다릴게: 그리움은 창가에 선 발끝 자세, 기다림은 옆자리를 비운 벤치 앉기로 구분한다.
- 지쳤어 / 속상해 / 망했다: 피곤함은 뒤로 기대고 다리를 내민 앉기, 슬픔은 무릎 앞에 손을 모은 앉기, 좌절은 양 무릎과 손을 바닥에 대는 자세다.
- 밥 먹었어? / 먹고 해 / 챙겨가: 식사 질문은 그릇 보여주기, 권유는 주머니 옆에서 한 입 건네기, 챙김은 한 무릎을 대고 도시락 닫아 밀어 주기다.
- 최고야 / 힘내: 칭찬은 곧게 선 기존 엄지척, 응원은 무릎을 굽히고 주먹을 몸 쪽으로 당기는 동작이다.

## 4행 × 8열 배치 제안

표의 번호는 관리용이며, 아래는 큰 실루엣이 연속해서 겹치지 않게 섞은 검토용 배치다. 각 숫자는 위 기획표 번호에 대응한다.

- 1행: 01 안녕! → 05 좋아! → 06 고마워 → 02 뭐해? → 21 밥 먹었어? → 04 지금 가! → 03 잘 자 → 27 기다릴게
- 2행: 25 사랑해 → 14 ㅋㅋㅋ → 07 최고야 → 24 보고 싶어 → 15 헉! → 26 안아줘 → 19 수고했어 → 29 괜찮아
- 3행: 08 싫어 → 17 집중 중 → 11 삐짐 → 16 잠깐만 → 28 미안해 → 12 지쳤어 → 09 모르겠어 → 20 힘내!
- 4행: 22 배고파 → 30 내가 할게 → 13 속상해 → 18 끝났다! → 10 망했다 → 23 맛있다 → 32 챙겨가 → 31 먹고 해

이 배치는 기획 단계의 동작 점검안이다. 32종 원화를 그린 뒤 동일 크기로 나란히 놓아 외곽선·손과 소품의 겹침을 다시 확인한다.
