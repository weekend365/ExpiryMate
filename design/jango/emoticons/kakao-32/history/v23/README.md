원문 기록의 경로는 역사적 참조이며 새 제작 입력이나 현재 승인으로 해석하지 않는다. 동일 바이트 원화는 v18·v24 보존본으로 조회하고, 삭제된 고유 시안은 당시 해시와 삭제 사실만 확인한다. 준비·생성·재사용 기록과 기존 불확실성은 원문 그대로 보존했다.
