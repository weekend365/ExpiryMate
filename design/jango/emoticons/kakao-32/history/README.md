# 장고 이모티콘 제작 이력

현재 디자인은 [v24 최종 32종](../v24/README.md), 캐릭터 MASTER는 [v18](../v18/README.md)이다. 2026-10-20 사용자 요청으로 v20~v23의 이미지·폰트 670개와 중복 진단 이미지 97개, 총 767개·316,344,917바이트를 제거했다. 이 폴더에는 제작 기록만 보존한다.

- [v20 기록](v20/README.md): 전신 배치·Gaegu Bold, 10·15번 새 포즈.
- [v21 기록](v21/README.md): 생활 친구 성격과 8종 표정·행동 확장.
- [v22 기록](v22/README.md): 감자꽃 서체·공통 크기·전신 비율, 최종 31종의 입력.
- [v23 기록](v23/README.md): 새 29번 ‘지쳤어...’, 최종 32종 선택 목록.
- [전체 삭제·이동·동일 바이트 보관 목록](../../../quality/history/emoticons-v20-v23/index.json) · [종료된 준비·후보·검수 기록](../../../quality/history/emoticons-v20-v23/README.md)

원문 JSON·프롬프트의 경로와 해시는 당시 기록 그대로다. 원문 Markdown은 `README.original.md.txt`로 보존하며 그 안의 경로는 과거 참조다. 이력 조회는 원래 경로와 해시를 함께 확인한 뒤 동일 바이트 보존본으로 연결한다. 파일 위치와 제작 계보는 별개이며 원래 계보의 출처·해시·순환 검사를 유지한다. 고유했던 이전 시안은 삭제 사실과 해시만 남고 현재 이미지로 재검증되지 않는다. 구버전 갤러리는 제거했다.

종료된 후보 97건은 출시·등록·재생성이 차단된다. v24의 기존 준비는 이력 처리와 문서 변경으로 `stale`이며 원래 준비 기록을 소급 수정하지 않았다. 기존 입 재검토 상태와 AI 제작 이력을 유지한다.

앞서 정리한 캐시 197개의 [원래 기록](../../../quality/cleanup/20261020.json)은 그대로다. 당시 재현 검증은 과거 사실이며 입력 시안이 이번에 종료되어 현재 재생성 대상으로 취급하지 않는다. `pnpm jango:history:cleanup --check`로 보존본·기록 무결성을, `pnpm jango:final:check`로 현재 최종본을 확인한다. 복구용 임시 사본은 전체 검증 후 제거하며 영구 이미지 ZIP은 만들지 않는다.
