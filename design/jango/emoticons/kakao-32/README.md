작화·형태의 활성 캐릭터 MASTER는 계속 [v18 원본 32종](v18/README.md)이다. 최종 이모티콘 디자인의 선택과 캐릭터 MASTER·앱 자산·서명된 이모티콘 출시는 구분한다. 신규 제작과 출처 보존은 [검수 안내](../../quality/README.md)를 따른다.

최종본 구성은 `pnpm jango:final:check`로 검증한다. 재사용한 원화의 실제 AI 제작 이력과 기존 입 재검토 상태를 유지한다.
