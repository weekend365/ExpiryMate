제작 당시 입 검사 9종 재검토는 종료 이력과 MASTER 목록에 보존한다. 현재 재측정은 별도로 기록한다. MASTER 채택과 앱 사용은 사용자 지시에 근거하며 외부 서명을 대신하지 않는다. 최종 이모티콘 출시는 jango:promote·jango:export를 따른다.

source-originals에는 선택된 32개 원화만 남겼다. 새 제작은 새 버전에서 jango:prepare로 시작한다. characters는 진단용 중앙 정렬이며 문구 없는 출력 비교에는 artwork를 사용한다. fonts에 Gaegu와 OFL·출처 해시를 보존한다.
