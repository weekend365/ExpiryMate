## v18과 품질 관문의 역할

[v18 32종 레지스트리](../master-set.json)는 원래 파일·해시·채택 이력을 그대로 보존한다. 24번은 구조/포즈 대표, 09·01·11·17번은 기본 입 구조와 기존 보수적 검사 기준이다. 새 스타일 장면 한 장을 32종 재작화·입 검수 완료로 간주하지 않는다.

`jango:prepare`는 정책 v6에서 `colored-pencil`을 기본으로 첨부한다. `handdrawn-crayon`은 과거 감사 전용이며 신규 준비에 사용하지 않는다. 이모티콘용 네 입 모드·투명 360px·여백·서명 조건과 불확실한 측정의 재검토는 유지한다. 기존 정량 검사가 새 연필 질감의 시각 품질을 인증하지 않는다. SNS의 미지원 표현은 [별도 준비·검토](../quality/README.md)를 따른다.

## 현재 적용과 남은 마이그레이션

이번 변경은 v19 활성 마스터·규칙·신규 준비 참조에만 적용했다. v19에는 승인된 기준이미지와 스타일 사양이 있으며, v19 32포즈 재작화는 0/32이고 앱 파생물도 미전환이다. v18 파일을 복사·이름 변경해 v19 완성 포즈로 표시하지 않는다. 기존 앱 PNG, 아이콘·스플래시, 배경, 공유 색 토큰과 32종 이모티콘 원화는 교체하지 않았다. 앱은 계속 `manifest.json`에 등록된 v18 runtime 파생물을 사용한다.

후속 작업은 새 스타일의 문구 없는 투명 포즈 후보 제작 → 크기별/밝고 어두운 배경 검토 → 사용자 채택 → runtime/브랜딩 매핑 갱신과 sync/build/audit → 화면 검토 순서다. 32종 이모티콘은 별도의 재작화·검수·서명 출시 과정이다. 이번 채택으로 자동 실행하지 않는다. 기존 앱 UI/UX, 흰색 얇은 테두리 말풍선과 글꼴 정책도 유지한다.
