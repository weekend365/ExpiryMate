# 장고 CHARACTER BIBLE — v19 공통 MASTER

사용자가 2026-10-09 채택한 [v19 MASTER](../masters/v19/master.json)가 앱·브랜딩·이모티콘·SNS·마케팅·영상의 활성 제작 기준이며 v18을 대체한다. v19 32포즈와 앱 파생물은 아직 미전환이다. [채택 이미지와 범위](./STYLE-MASTER-ADOPTION.md)를 먼저 확인한다. 장면 속 장고의 선·채색·명암·종이 질감을 따르며 여성·배경·두부·대사를 필수 요소로 복제하지 않는다.

[v18 32종](../master-set.json)은 역사적 원본·포즈·구조 참조다. 구조 대표는 **24번 완성!**이다. 원화와 360px 스티커, 레터링 바이트를 보존하며 새 스타일로 재작화·검수된 32종으로 표시하지 않는다. 기존 앱 runtime은 별도 마이그레이션 전까지 이 원본의 파생물을 유지한다.

## 적용 범위

- **MASTER 보존:** 원본 파일·해시·채택 이력은 보존한다. 창작을 위한 변형은 별도 파생본에 적용한다.
- **기본형 재현·앱 파생·현행 이모티콘 검수:** 아래 기본 실루엣·표정 구조와 v19 연필 스타일을 따른다. 기존 v18 runtime 재현과 과거 검수는 당시 원본/기준을 유지한다. 앱 에셋 파생과 이모티콘 제출 규격·서명 관문은 SNS 허용 범위로 변경하지 않는다.
- **SNS 카툰 파생물:** 아래 「SNS 카툰의 표현 확장」을 적용한다. 기본형의 비율·좌우 배치·입 네 모드·색을 모든 파생물의 절대 상한으로 삼지 않는다. 표현 확장의 허용은 개별 결과의 자동 채택이 아니다.

## 참조와 우선순위

- 선·색·명암·질감: [활성 v19 MASTER](../masters/v19/master.json)의 승인된 장고가 우선이다.
- 형태·동작·구조: 24번과 해당 v18 원화를 참고한다. 경로·해시는 기존 32종 목록에서 읽고, 과거의 굵은 크레파스 선·평평한 밝은 색면을 새 그림체보다 우선하지 않는다.
- 기본 입 참조: U는 09번, 열린 입은 01번, 중립 선은 11번, 처진 선은 17번 원화. SNS의 새 입은 사용한 기본 참조와 달라진 표현 의도를 함께 기록한다.
- 구성: [v18 구성 보드](./v18-composition.png)의 해당 번호. 보드는 선택 원화의 파생 화면이며 별도의 캐릭터 설계가 아니다.
- 정체성·입·장갑 구조는 보존하고, 그림체 판단은 v19 활성 MASTER를 우선한다. 감정·자세·소품·매체 연출은 그 역할과 적용 범위를 구분한다. 이 문서와 [스타일 가이드](./JANGO-STYLE-GUIDE.md)를 함께 적용한다.
- 아래 상대 비율은 기본형을 재현하기 위한 목표다. 선택된 32종을 모두 같은 정면 자세로 실측·승인했다는 뜻이 아니다. 실제 자세의 원근·가림을 존중하며 수치에 맞추려고 MASTER 원화를 늘이거나 줄이지 않는다. SNS의 의도적인 비율 과장은 별도 파생본으로 검토한다.

## 기본 실루엣과 구조

큰 냉장고 문 자체가 머리이며 아래에 작은 앞치마 몸통과 짧고 통통한 팔다리가 연결된다. 얼굴 폭 W, 높이 F, 전체 키 T는 각 원화의 실제 외곽에서 읽는다. 정면 제작 목표 W:F는 약 1.28:1, W:T는 약 0.52:1이다. 몸통은 약 0.57W 폭·0.40W 높이, 팔은 장갑 제외 약 0.18W 길이, 골반–발목 구조 길이는 약 0.12W다. 동작은 관절·원근으로 표현한다.

- 모자는 중앙 하나와 양옆 두 쌍의 **다섯 주요 볼륨**, 높은 중앙 봉우리, 민트 밴드, 아이보리 천색을 유지한다. 날카로운 주름·모자 증식·풍선처럼 늘어남은 금지한다.
- 냉장고 얼굴은 둥근 사각형의 한 문이다. 바깥 윤곽과 안쪽 도어 테두리는 의도된 구조선이다. 상하 문 분할·문 열기·버튼·추가 로고를 만들지 않는다.
- 기본형 재현에서는 관찰자 기준 **왼쪽 세로 손잡이와 파인애플, 오른쪽 경첩 두 개**를 유지한다. SNS 좌우 반전은 아래 표현 확장 절차에서 구조 변화와 보정 필요성을 검토한다.
- 파인애플은 작은 노란 타원 열매·초록 잎·대각 격자다. 독립 소품처럼 위치를 바꾸지 않는다.
- 몸통은 짧은 사다리꼴 앞치마, 포켓, 흰 소매를 유지한다. 목·코·귀·꼬리·피부를 추가하지 않는다.
- 장갑은 둥근 벙어리 주머니·**기존 엄지 하나**·손목 커프스 구조다. 검지·다섯 손가락·발가락을 만들지 않는다. 엄지척은 기존 엄지로, 가리키기는 장갑 전체 방향으로 표현한다.
- 팔과 장갑, 장갑과 소품의 연결이 읽혀야 한다. 소품 때문에 손이 늘어나거나 커프스가 사라지면 안 된다.
- 신발은 낮고 둥근 민트 덩어리와 단순 밑창이다. 끈·굽·복잡한 패널을 추가하지 않는다.
- 측면의 머리는 얕은 둥근 사각 상자다. 확장 깊이 목표 0.20W를 쓰되 v18에 없는 뒷면 설계를 실제 MASTER 실측으로 주장하지 않는다.

## 기본 얼굴과 표정

기본 눈은 어두운 세로 타원이며 흰자·분리 동공·반짝이를 넣지 않는다. 눈 중심 간격의 정면 제작 목표는 약 0.388W다. 미세 비대칭을 보존하고 빈 공간을 기준으로 표정을 임의 재정렬하지 않는다. 감은 눈·윙크·눈썹은 해당 v18 감정 컷을 참조한다.

- 감정 때문에 눈·입 전체를 아래로 내리거나 눈 간격을 좁히지 않는다. 정면 눈 중심 이동 목표는 수평 ±0.015W·수직 ±0.020F 이내, 입 중심은 수평 ±0.015W·수직 ±0.025F 이내다.
- 볼터치는 분홍 살구색이다. 손·소품에 가려질 수 있지만 감정 때문에 삭제하지 않는다.
- **idle-u:** 짧고 둥근 단일 U선. 내부 채움·혀·치아 없음.
- **speak-open:** 완만한 윗변과 둥근 아래쪽, 검은 입 안과 하단 중앙의 작은 분홍 혀. 혀에 별도 검은 테두리 없음.
- **neutral-line:** 둥근 끝의 짧은 수평선. 채움·혀·치아 없음.
- **sad-arc:** 중앙보다 양 끝이 아래인 작은 ∩ 곡선. 채움·혀·치아 없음.
- 선형 입은 기본 U 입 폭의 약 80–100%, 처진 곡선 높이는 폭의 약 15–25%를 목표로 한다. 입술 링·빈 O형·치열·입 전체 분홍 채움·내민 혀는 금지한다.
- 놀람은 타원 눈·눈썹·speak-open·멈칫하는 자세로 표현한다. 별도 놀람 입을 만들지 않는다.
- 소품은 해당 컷에만 속한다. 24번 음식 접시도 캐릭터의 영구 신체 특징이 아니다.

## 공통 연필 표현과 색

승인 장면의 장고를 기준으로 따뜻한 갈색·엄버 연필 윤곽과 가는 획의 압력 변화를 사용한다. 크림·황토 농담을 겹친 모자·얼굴·앞치마, 차분한 민트의 채색 변화, 살구 볼터치를 유지한다. 굵고 균일한 짙은 외곽선·형광 민트·평평한 밝은 흰색 때문에 캐릭터만 스티커처럼 튀지 않게 한다.

모자 주름·문 가장자리·소매·장갑·앞치마에 부드러운 형태·접촉 명암과 주변의 따뜻한 색을 쌓는다. 색면 안의 방향성 연필 획과 종이 결을 보존하되, 주요 구조선이나 눈·입 중심이 끊기지 않아야 한다. 무광의 연필 채색을 광택·3D 그라데이션·후광으로 대체하지 않는다. 투명 구멍·캐릭터 밖 먼지를 질감으로 만들지 않으며 투명 캐릭터 PNG에는 종이 바탕을 포함하지 않는다.

기존 [크레파스 팔레트](./styles/crayon-palette.json)는 v18 역사적 색 기록이다. 새 스타일의 고정 hex 팔레트나 현재 앱 토큰 변경 지시가 아니다. 승인 이미지와 [채택 기록](./STYLE-MASTER-ADOPTION.md)의 실제 선·색·명암 관계를 기준으로 검토하며, 원본을 재채색하지 않는다.

## SNS 카툰의 표현 확장

연재 매체의 장면 통합·연출·한글·360px 읽힘·기능 전달은 [승인 v6 기록](../cartoon-series.json)과
[SNS 카툰 제작·검수 기준](./SNS-CARTOON-GUIDE.md)을 따른다. v19 캐릭터 정본과 아래 표현 확장은
유지하며, v6의 특정 등장인물·공간·네 컷 구도를 후속 회차의 필수 요소로 고정하지 않는다.

장고로 알아볼 수 있는 일관성을 검토하면서 표정·입·포즈·소품·의상·원근·비율 과장·좌우 반전·색 변형을 허용한다. 위 기본형의 금지·유지 문구를 이유로 이 변형들을 일괄 거부하지 않는다. 원본을 덮어쓰지 않고, 의도한 변화와 우발적인 구조·질감 손상을 구분한다.

| 변형 | 제작·검토 기준 |
|---|---|
| 표정·입 | 입만 교체하거나 네 기본 모드 밖의 입을 만들 수 있다. 눈·눈썹·입의 감정 일치, 얼굴과의 연결, 기존 입 제거 흔적·질감 이음새·작은 출력의 읽힘을 확인한다. 새 입을 기존 모드로 거짓 분류해 검사하지 않는다. |
| 포즈·원근·비율 | 동작과 감정을 위한 과장을 허용한다. 머리·몸·팔다리 연결, 가림과 원근, 회차 사이 캐릭터 인지의 일관성을 확인한다. 기본형 수치에 맞추기 위한 보정과 의도한 과장을 혼동하지 않는다. |
| 소품·의상 | 추가·교체·이동·제거를 허용한다. 손과 소품의 접촉, 장갑·팔의 연결, 의상과 몸의 가림, 장면 맥락을 확인한다. MASTER의 소품은 영구 신체 특징이 아니다. |
| 좌우 반전 | 반전 후보를 원본과 비교해 손잡이·경첩·파인애플·소품·글자·빛 방향의 변화를 확인한다. 반전 그대로 채택, 필요한 부분 보정, 반대 방향 새 작화 중 장면에 맞는 방식을 선택하고 검토 결과를 기록한다. 구조 변화만으로 일괄 금지하거나 자동 채택하지 않는다. |
| 색 | 장면·감정·계절·의상에 따른 색 변형을 허용한다. 표정 대비, 최신 연필 선과 겹채색·종이 결, 장고로 읽히는 일관성, 인접 컷의 연속성을 확인한다. MASTER를 새 팔레트로 덮어쓰지 않는다. |

단순 배치·반전·검토된 색 또는 레이어 조합은 오프라인 합성을 우선한다. 손의 연결·얼굴·가림·질감을 다시 그려야 하면 별도 작화나 이미지 편집 후보로 만든다. 재사용 자산의 범위를 넓힌다는 이유로 매번 새 생성을 요구하지 않는다.

`후보 → 비교 검토 → 필요시 보정·재검토 → 사용자 SNS 채택 → 재사용` 순서를 따른다. 제작 기록에는 고유 ID, MASTER까지 이어지는 출처와 파일 해시, 사용한 참조, 목적·변경 영역·방법, 검토 결과·미해결 사항, 사용자의 채택 근거와 사용 범위를 남긴다. 채택된 SNS 파생본을 다시 변형하면 새 후보이며, 이전 채택이 새 결과에 자동 승계되지 않는다.

어떤 정체성 요소를 어느 정도 유지할지와 새 변형의 허용 강도는 사용자 검토로 결정한다. 에이전트가 모든 변형을 승인하거나 새 정체성 규칙을 임의로 고정하지 않는다. 일반 SNS 채택만으로 공통 MASTER·앱 에셋·서명 출시가 자동 변경되지는 않는다. 이번 v19 활성 MASTER는 별도의 명시적 공통 채택 요청을 기록한 것이며, 앱 에셋 교체와 서명 출시는 포함하지 않는다. 현재 도구가 지원하는 검사 범위와 SNS 제작 기록은 [검수 안내](../quality/README.md)에서 구분한다.

## 제작과 검수

[준비 절차](../quality/README.md)에서 제작 매체·입 표현·선택 이유·감정·눈·눈썹·자세와 실제 참조를 기록한다. 현행 이모티콘 준비에서는 입 모드와 강도 등 기존 계약을 유지한다. 생성 문구는 사용하지 않고 글자를 별도 조립하며 이모티콘은 Gaegu 기준을 따른다. 기본형 재현에서는 모자·얼굴·핵심 장갑·소품을 보존하고 하반신 프레이밍을 명시한다. SNS에서는 의도한 변형·프레이밍과 우발적 잘림을 구분해 검토한다.

MASTER 채택은 사용자의 디자인 선택이다. 기존 9종의 입 재검토와 현재 정책의 측정 결과를 구분해 보존한다. 자동 통과는 디자인 승인이나 외부 서명이 아니며, 최종 이모티콘 채택·출력은 `jango:promote`·`jango:export`를 따른다. 검수 서명이나 통과를 위한 가짜 ROI를 만들지 않는다.
