# 장고 STYLE GUIDE — v18 MASTER

[BIBLE](./JANGO-CHARACTER-BIBLE.md)와 [MASTER 목록](../master-set.json)을 따른다. 모든 신규 장고 제작은 이 32종에서 출발한다. 기본 대표는 24번이다.

## 제작

- 필요한 v18 원화를 선택하고 `jango:prepare`로 새 작업을 준비한다. 원화를 필터로 변형하거나 얼굴 비율·입 구조를 임의로 고치지 않는다.
- 형태·그림체 대표와 동작 원화, 선택 입 참조를 역할별로 첨부한다. 같은 파일은 한 번만 첨부하고 최대 5개를 지킨다.
- 크레파스의 단일 윤곽, 불투명 색면, 민트·차콜·살구 볼터치, 약한 질감과 진한 표정을 유지한다.
- 원화는 전신·모자·손·소품이 잘리지 않게 만든다. 상반신 출력은 원본을 남기고 프레이밍을 별도 기록한다.

## 작은 출력과 글자

- 얼굴 폭 48px 미만에서는 미세 입자·봉제선보다 표정과 구조선의 읽힘이 우선이다. 파생 과정에서 얼굴을 다시 그리지 않는다.
- 이모티콘 레터링은 Gaegu Regular를 기본으로 하고 읽힘이 부족한 짧은 반응만 Bold를 쓴다. 폰트 파일·OFL·출처 해시는 v18에 보존한다.
- 글자는 별도 레이어로 조립한다. 정확한 문구·읽기 순서를 유지하고 기울기는 ±10도 이내다. 흰 외곽선은 밝고 어두운 배경에서 필요한 최소 두께다.
- 동작 주변 빈 공간을 사용한다. 문구 없는 비교는 실제 배치에서 글자만 제거한 이미지다.
- 투명 360px PNG와 최소 8px 여백, 투명 가장자리, 글자 충돌, 원화 잘림을 검사한다. 80px·120px의 밝고 어두운 배경도 관찰한다.

## 앱·브랜딩·영상

- 앱은 문구 없는 원화에서 균일 비율로 파생한다. 24번을 기본·아이콘·스플래시에 사용한다. 기존 Mascot mood·size API와의 호환성을 유지한다.
- 앱의 시각 표현·배치·장고 상호작용은 [디자인 시스템](../../../docs/design-system.md)을 따른다. 화면을 수정하는 범위부터 적용하며 구현 예정인 컴포넌트 사용을 현재 요구하지 않는다.
- 크레파스 팔레트는 캐릭터 전용이다. UI 기능 색상에 직접 대입하지 않는다. UI 표현 변경은 공유 semantic token의 역할·대비를 검증해 반영하며 상태·기한 색의 의미와 Admin의 기존 기준은 유지한다.
- 앱 UI 글꼴은 Pretendard, Gaegu는 짧은 브랜드 보조 문구에 제한한다. 필수 정보 뒤에는 질감을 넣지 않는다.
- 영상에서도 얼굴·장갑·모자의 구조를 유지한다. 이동·회전 때문에 질감이 깜박이거나 새 부품이 생기지 않게 검토한다.
- 검수 중 불확실성은 그대로 기록한다. MASTER 지정·앱 파생 허용과 서명된 이모티콘 출시를 구분한다.
