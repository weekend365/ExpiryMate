# 장고 STYLE GUIDE — v18 원본 MASTER

[BIBLE](./JANGO-CHARACTER-BIBLE.md), [v18 활성 MASTER](../style-master.json), [복원 범위](./STYLE-MASTER-ADOPTION.md)와 [MASTER 목록](../master-set.json)을 따른다. 모든 신규 장고 제작은 [source-originals 32종](../emoticons/kakao-32/v18/source-originals)에서 출발하며 SNS에서 채택한 파생본도 MASTER까지의 계보를 보존한다. 기본 대표는 24번이다. v19 교체 작업은 중단했으며 기존 앱 에셋은 유지한다. MASTER 보존, 기본형 재현, SNS 표현 확장의 적용 범위는 BIBLE을 따른다.

## 제작

- 필요한 v18 원화 또는 출처·사용 범위가 기록된 SNS 채택 파생본을 선택한다. 원본 파일은 보존하며 비율·입·색 등의 창작 변형은 별도 후보에 적용한다. 현행 이모티콘·스타일 참조 후보는 `jango:prepare`, SNS는 [검수 안내](../quality/README.md)의 매체별 준비를 따른다.
- 형태·그림체 대표와 동작 원화, 선택 입 참조를 역할별로 첨부한다. 같은 파일은 한 번만 첨부하고 최대 5개를 지킨다.
- 기본형은 크레파스의 단일 윤곽, 불투명 색면, 민트·차콜·살구 볼터치, 약한 질감과 진한 표정을 유지한다. SNS 색·의상·표정 변형은 BIBLE의 표현 확장 기준으로 구조·질감·캐릭터 인지를 검토한다.
- 새 앱 작화는 모자·양팔·장갑·앞치마·두 다리·두 신발이 모두 보이는 전신을 기본으로 한다. 하반신이 생략된 MASTER는 원본 그대로 보존하고, 확장은 전신 원화의 구조·비율을 따른 별도 후보로 만든다. 단순 resize로 하반신을 만들거나 원본을 덮어쓰지 않는다. SNS의 의도한 소품·가림·장면 프레이밍은 별도 기록·검토한다.

## 작은 출력과 글자

SNS의 레터링·장면 연출·모바일 검수는 [승인 v6 제작 기준](./SNS-CARTOON-GUIDE.md)을 따른다. 캐릭터 MASTER와 구분된 매체 기준이며 앱·이모티콘의 말풍선·글꼴·출력 규격을 바꾸지 않는다.

- 얼굴 폭 48px 미만에서는 미세 입자·봉제선보다 표정과 구조선의 읽힘이 우선이다. 단순 크기 파생 과정에서 얼굴을 몰래 다시 그리지 않는다. SNS의 얼굴 수정은 별도 후보로 기록·검토한 뒤 사용한다.
- 이모티콘 레터링은 Gaegu Regular를 기본으로 하고 읽힘이 부족한 짧은 반응만 Bold를 쓴다. 폰트 파일·OFL·출처 해시는 v18에 보존한다.
- 글자는 별도 레이어로 조립한다. 정확한 문구·읽기 순서를 유지하고 기울기는 ±10도 이내다. 흰 외곽선은 밝고 어두운 배경에서 필요한 최소 두께다.
- 동작 주변 빈 공간을 사용한다. 문구 없는 비교는 실제 배치에서 글자만 제거한 이미지다.
- 이모티콘은 투명 360px PNG와 최소 8px 여백, 투명 가장자리, 글자 충돌, 원화 잘림을 검사한다. 80px·120px의 밝고 어두운 배경도 관찰한다. SNS 컷은 정한 출력 크기와 실제 열람 크기에서 글자·표정·배치·합성 경계를 검토한다.

## 앱·브랜딩·영상

- 앱은 문구 없는 원화에서 균일 비율로 파생한다. 24번을 기본·아이콘·스플래시에 사용한다. 기존 Mascot mood·size API와의 호환성을 유지한다.
- 앱의 시각 표현·배치·장고 상호작용은 [디자인 시스템](../../../docs/design-system.md)을 따른다. 손그림 스타일은 캐릭터·배경 이미지에만 적용하고 카드·말풍선·버튼·제목·기능 아이콘·UI 글꼴에는 확장하지 않는다. 기존 화면의 장면·구도·정보 묶음·조작 위치를 유지하며 철회한 전체 개편·크레파스 UI 장식·v19 교체는 자동 재개하지 않는다.
- 크레파스 팔레트는 캐릭터 전용이다. UI 기능 색상에 직접 대입하지 않는다. UI 표현 변경은 공유 semantic token의 역할·대비를 검증해 반영하며 상태·기한 색의 의미와 Admin의 기존 기준은 유지한다.
- 앱 UI 글꼴은 Pretendard를 유지한다. 캐릭터·SNS·이모티콘 이미지의 레터링 규칙을 UI 글꼴에 적용하지 않는다. 필수 정보 뒤에는 질감을 넣지 않는다.
- 영상에서는 채택된 디자인의 구조·질감이 프레임 사이에서 일관적인지 확인한다. SNS의 의도한 변형과 이동·회전 중 우발적으로 생긴 부품·질감 깜박임을 구분한다.
- SNS 변형 허용은 앱의 비율 유지 파생, 기존 흰색 면·얇은 테두리·왼쪽 꼬리 말풍선, 이모티콘 제출 규격을 변경하지 않는다.
- 검수 중 불확실성은 그대로 기록한다. MASTER 지정·앱 파생 허용·사용자 SNS 채택·서명된 이모티콘 출시를 구분한다. 개별 변형 종류의 허용·검토 기준은 BIBLE에만 두며 중복 규칙을 만들지 않는다.
