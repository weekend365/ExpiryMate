# JANGO IMAGE PROMPTS v1

이미지 생성 AI용 자연어 프롬프트 · 2026-09-29

근거: jango-idle MASTER · JANGO CHARACTER BIBLE v1 · JANGO STYLE GUIDE v1 · JANGO TEST POSE 6.

## 사용 방법

- 생성 시 jango-idle 원본을 실제 이미지로 첨부하고 **참조 이미지 1**로 지정한다. 파일명만 입력하는 것은 시각 참조를 전달하는 것과 다르다.
- 한 번에 한 포즈를 요청한다. 아래 각 포즈의 **긍정 프롬프트 전체 + Negative instruction 전체**를 사용한다. 별도의 negative 입력란이 없다면 같은 요청의 마지막에 이어 붙인다.
- 각 긍정 프롬프트에는 정체성 규칙을 반복해 넣었으므로 다른 포즈의 본문을 함께 붙일 필요가 없다. 여섯 포즈를 한 화면에 동시에 그리도록 요청하지 않는다.
- 좌우는 모두 관찰자 기준 화면 좌우다. 각도는 TEST POSE의 연출 출발값이다. 얼굴 폭과 높이는 기울기 전 냉장고 문 기준이며, 회전 후에도 문 내부의 상대 좌표를 유지한다.
- BIBLE의 약한 시선 이동은 THINKING과 COOKING에만 명시했다. 이는 눈을 따로 움직이거나 간격을 바꾸는 허용이 아니다. 감은 눈은 타원의 세로 크기 대신 승인된 곡선 형태를 사용한다.
- 수정 시 **이미지 1 = MASTER / 이미지 2 = 수정할 결과**로 첨부한다. 각 edit prompt는 지정한 대표 오류가 실제로 있을 때 사용하는 부분 수정용이다. 서로 다른 오류는 해당 영역을 지정해 한 번씩 수정한다.
- ‘오류가 자주 발생할 요소’는 기존 분석과 구조를 바탕으로 우선 확인할 항목이다. 이번 프롬프트로 새 이미지를 생성해 발생 빈도를 측정한 결과는 아니다.

이미지 생성·원본 수정은 수행하지 않았다. 아래 각 포즈의 유지 조건은 공통 정체성 규칙에 더해 특별히 확인할 사항이다.


## 1. IDLE — 차분히 기다리는 기본 자세

### 1. 긍정 프롬프트

참조 이미지 1은 jango-idle MASTER다. 정면 카메라와 MASTER의 배경 상태를 유지하고, 같은 장고 한 명의 전신을 표현한다. 새로운 캐릭터를 디자인하지 않는다. 여섯 포즈는 같은 캔버스와 같은 얼굴 크기를 사용하며, 모자·장갑·발·소품이 잘리지 않게 배치한다. 좌우는 보는 사람의 화면 기준이다.

MASTER의 냉장고 문 자체가 얼굴이다. 가로가 세로보다 조금 긴 얼굴 비율 약 1.28:1, 모서리 곡률, 이중 문 테두리, 머리보다 작은 몸통, 짧은 팔과 다리, 둥근 신발을 유지한다. 화면 왼쪽의 민트 손잡이와 그 위 파인애플, 화면 오른쪽의 회색 경첩 두 개를 그대로 둔다. 머리가 움직이면 눈·입·양쪽 민트 볼터치·손잡이·장식·경첩도 문에 붙은 상태로 함께 움직인다. 모자는 머리와 함께 움직이며, 가장 높은 중앙 볼륨과 양옆 두 개씩의 볼륨으로 이루어진 다섯 덩어리, 기존 주름, 민트 밴드, 얼굴 대비 폭과 높이를 유지한다.

열린 눈은 MASTER와 같은 검정 세로 타원이며, 각 눈 크기와 두 눈 중심 간격을 유지한다. 눈 중심 간격은 얼굴 폭의 약 39%이고, 입은 MASTER의 기본 기준점에 둔다. 감은 눈은 아래 포즈에서 지정한 곡선으로 바꾸되 두 눈의 기준 중심과 간격을 유지한다. 두 장갑은 각각 네 손가락이 함께 들어가는 둥근 주머니 하나, 옆으로 분리된 엄지 주머니 하나, 손목 커프스 하나로 구성된 민트 오븐 벙어리장갑이다. 앞치마의 민트 테두리·끈·둥근 포켓도 유지한다.

색상은 MASTER에서 유지한다. 본체·모자·앞치마의 아이보리는 #FDF8F2, 주요 민트 포인트는 #66C6A3 계열, 장갑은 #65C3A0, 볼터치는 #CCE0CF, 윤곽선은 #302E2C, 눈·입은 #1B1B19, 파인애플 노랑은 #F5C93E를 기준으로 한다. 같은 민트색 안의 부위별 원래 차이도 보존한다. 손그림의 완만한 곡선과 둥근 선 끝을 유지한 간결한 2D로 표현한다. 선의 잔떨림만 정리하고, 성긴 퀼팅과 필요한 구조선을 남긴다. 외곽선보다 내부선은 가늘게, 표정선은 선명하게 표현한다. 기본색과 옅은 접촉 그림자 한 단계만 사용하고, 기존 손잡이의 작은 하이라이트를 유지한다. 이 정체성 규칙을 유지한 채 아래 표정과 자세만 적용한다.

편안하게 다음 행동을 기다린다. 머리와 모자를 수평으로 두고 몸 중심을 두 발 사이에 놓아 곧게 선다. MASTER와 같은 크기·간격·높이의 검정 세로 타원 눈 두 개와 기본 위치의 작은 U자 미소를 그린다. 눈썹은 없다. 양팔은 낮게 바깥으로 열고, 손목은 얼굴 아래 모서리보다 낮게 둔다. 두 장갑은 앞치마를 가리지 않으며, 둥근 주머니와 엄지 하나씩이 보인다. 두 발을 MASTER의 기본 간격으로 바닥에 붙이고 신발 끝은 조금 바깥을 향한다. 소품은 없다. 낮게 열린 양팔과 안정된 두 발이 작은 크기에서도 먼저 읽히게 한다.

### 2. 반드시 유지할 특징

- MASTER의 열린 타원 눈 크기·간격·높이, 작은 U자 입과 양쪽 볼터치.
- 모자·냉장고·몸·장갑·신발의 기본 비율과 고정 부품의 방향.
- 두 발로 선 균형과 낮게 열린 양팔.

### 3. 변경 가능한 특징

- 이번 IDLE은 비교 기준이므로 표정·머리 각도·팔다리 자세를 MASTER에 맞춘다.
- 확정 스타일 범위의 선 잔떨림 정리와 과밀한 보조 디테일 축소만 적용한다. 소품은 추가하지 않는다.

### 4. Negative instruction

다른 캐릭터, 새 친구, 캐릭터 복제, 유명 캐릭터를 연상시키는 얼굴이나 스타일을 추가하지 않는다. 얼굴 가로세로 비율, 눈 간격, 머리와 몸의 크기 관계, 모자 크기와 다섯 볼륨, 문 구조를 변경하지 않는다. 손잡이·파인애플·경첩을 이동하거나 좌우 반전하지 않는다. 팔·다리를 늘이거나 몸통을 찌그러뜨리지 않는다. 코·귀·새 목·흰자·동공·홍채·속눈썹·눈 반짝이를 추가하지 않는다. 장갑에 분리된 검지나 나머지 손가락, 다섯 손가락, 손톱, 손가락 마디, 두 번째 엄지를 만들지 않는다. 퀼팅 선을 손가락 경계로 바꾸지 않는다. 팔·다리·장갑을 추가하거나 서로 합치지 않는다. 색상·선화·명암 스타일을 변경하지 않는다. 과도한 3D, 플라스틱 광택, 강한 그라데이션, 두껍고 균일한 테두리, 완전히 무질감인 플랫 아이콘으로 바꾸지 않는다. 그림 안에 글자·포즈 이름·워터마크·말풍선·물음표·감탄사·속도선·반짝이·눈물·떠다니는 하트를 넣지 않는다. 지정하지 않은 소품이나 배경 장면을 추가하지 않는다.

눈썹, 벌어진 입, 혀, 치아를 추가하지 않는다. 고개를 기울이거나 손을 얼굴 높이로 들거나 한 발을 들지 않는다. 팔을 축 늘어뜨려 슬픈 자세로 바꾸지 않는다.

### 5. 오류가 자주 발생할 요소

- 눈을 더 크고 가깝게 배치해 인상이 달라짐.
- 선 정리 과정에서 모자의 볼륨·문 테두리·양쪽 볼터치가 누락됨.
- 입을 크게 열거나 양팔을 처뜨려 기본 감정이 바뀜.

### 6. 수정 작업 시 사용할 edit prompt

참조 이미지 1은 jango-idle MASTER이며 캐릭터의 구조·색상·선화 기준이다. 이미지 2는 수정할 현재 포즈다. 이미지 2에서 아래에 지정한 오류 영역만 수정한다. MASTER의 IDLE 자세를 이미지 2에 복사하지 않는다. 수정 대상 외의 표정·머리 각도·팔과 다리 자세·소품·배경·구도·캐릭터 크기는 이미지 2 그대로 유지한다. 얼굴 비율, 눈 중심 간격, 모자의 다섯 볼륨, 냉장고 문 구조, 화면 왼쪽 손잡이와 파인애플, 오른쪽 두 경첩, 짧은 팔다리, 주머니 하나와 엄지 하나의 장갑 구조, 원래 팔레트와 2D 선화를 유지한다.

눈 크기·간격과 입 위치가 달라진 경우, 얼굴 표정 영역만 수정한다. 두 눈을 이미지 1과 같은 크기의 검정 세로 타원으로 복원하고, 각 중심을 MASTER의 문 내부 상대 위치에 맞춘다. 두 눈 중심 간격은 얼굴 폭의 약 39%로 맞추되 MASTER의 미세한 비대칭을 임의로 대칭화하지 않는다. 입은 기본 기준점의 작은 U자 미소로 되돌린다. 추가된 눈썹·눈 반짝이·혀·치아가 있다면 제거한다. 냉장고 외곽과 양쪽 볼터치, 수평인 모자, 낮게 열린 양팔, 접지한 두 발은 그대로 유지한다.

### 2. 반드시 유지할 특징

- 감은 눈의 기준 중심과 눈 간격, 입의 기준점, 양쪽 민트 볼터치.
- 머리·모자·몸·팔다리·신발·장갑의 구조 크기.
- 왼발 접지와 오른발 들림, 얼굴 아래 바깥쪽에 위치한 두 장갑.

### 3. 변경 가능한 특징

- 눈을 ∩ 곡선으로 닫고, 입을 작은 열린 U형으로 바꾼다.

### 6. 수정 작업 시 사용할 edit prompt

참조 이미지 1은 jango-idle MASTER이며 캐릭터의 구조·색상·선화 기준이다. 이미지 2는 수정할 현재 포즈다. 이미지 2에서 아래에 지정한 오류 영역만 수정한다. ## 6. LOVE — 작은 하트를 몸 가까이 안는 자세

### 1. 긍정 프롬프트

참조 이미지 1은 jango-idle MASTER다. 정면 카메라와 MASTER의 배경 상태를 유지하고, 같은 장고 한 명의 전신을 표현한다. 새로운 캐릭터를 디자인하지 않는다. 여섯 포즈는 같은 캔버스와 같은 얼굴 크기를 사용하며, 모자·장갑·발·소품이 잘리지 않게 배치한다. 좌우는 보는 사람의 화면 기준이다.

MASTER의 냉장고 문 자체가 얼굴이다. 가로가 세로보다 조금 긴 얼굴 비율 약 1.28:1, 모서리 곡률, 이중 문 테두리, 머리보다 작은 몸통, 짧은 팔과 다리, 둥근 신발을 유지한다. 화면 왼쪽의 민트 손잡이와 그 위 파인애플, 화면 오른쪽의 회색 경첩 두 개를 그대로 둔다. 머리가 움직이면 눈·입·양쪽 민트 볼터치·손잡이·장식·경첩도 문에 붙은 상태로 함께 움직인다. 모자는 머리와 함께 움직이며, 가장 높은 중앙 볼륨과 양옆 두 개씩의 볼륨으로 이루어진 다섯 덩어리, 기존 주름, 민트 밴드, 얼굴 대비 폭과 높이를 유지한다.

열린 눈은 MASTER와 같은 검정 세로 타원이며, 각 눈 크기와 두 눈 중심 간격을 유지한다. 눈 중심 간격은 얼굴 폭의 약 39%이고, 입은 MASTER의 기본 기준점에 둔다. 감은 눈은 아래 포즈에서 지정한 곡선으로 바꾸되 두 눈의 기준 중심과 간격을 유지한다. 두 장갑은 각각 네 손가락이 함께 들어가는 둥근 주머니 하나, 옆으로 분리된 엄지 주머니 하나, 손목 커프스 하나로 구성된 민트 오븐 벙어리장갑이다. 앞치마의 민트 테두리·끈·둥근 포켓도 유지한다.

색상은 MASTER에서 유지한다. 본체·모자·앞치마의 아이보리는 #FDF8F2, 주요 민트 포인트는 #66C6A3 계열, 장갑은 #65C3A0, 볼터치는 #CCE0CF, 윤곽선은 #302E2C, 눈·입은 #1B1B19, 파인애플 노랑은 #F5C93E를 기준으로 한다. 같은 민트색 안의 부위별 원래 차이도 보존한다. 손그림의 완만한 곡선과 둥근 선 끝을 유지한 간결한 2D로 표현한다. 선의 잔떨림만 정리하고, 성긴 퀼팅과 필요한 구조선을 남긴다. 외곽선보다 내부선은 가늘게, 표정선은 선명하게 표현한다. 기본색과 옅은 접촉 그림자 한 단계만 사용하고, 기존 손잡이의 작은 하이라이트를 유지한다. 이 정체성 규칙을 유지한 채 아래 표정과 자세만 적용한다.

고마운 마음을 소중히 안는다. 머리와 모자를 화면 왼쪽으로 약 6도 함께 기울이고 몸통은 거의 수직으로 둔다. 눈은 원래 두 눈 중심 부근의 완만한 ∩ 곡선으로 감고 눈 간격을 유지한다. 입은 기본 기준점의 작은 닫힌 U자 미소이며 폭은 얼굴 폭의 약 12%다. 눈썹은 없고 양쪽 민트 볼터치를 유지한다. 양팔을 굽혀 얼굴 아래·앞치마 앞의 작은 하트를 몸 가까이 감싼다. 팔꿈치는 몸 가까이에 두고, 두 장갑의 둥근 주머니로 하트 양옆과 아래를 받치며 엄지 하나씩을 안쪽에 댄다. 두 커프스는 각각 구분되게 보인다. 하트 위쪽 홈은 남기고 얼굴은 가리지 않는다. 두 발은 조금 가까이 놓아 모두 바닥에 붙이며 한 무릎만 아주 약하게 이완한다. 하트는 파인애플과 같은 노랑 #F5C93E의 단순한 소품 하나로, 폭은 얼굴 폭의 약 36%, 높이는 얼굴 폭의 약 30%다. 하트에 얼굴·팔다리·글자는 없다. 앞으로 내밀지 않고 몸에 붙여 안는 팔과 기울인 머리로 다정함을 전달한다.

### 4. Negative instruction
