# JANGO TEST POSES v3 — 픽셀 정밀 보정본

2026년 9월 29일. jango-idle MASTER와 JANGO CHARACTER BIBLE v1을 기준으로 v2의 남은 차이를 직접 픽셀 편집했습니다. 이번 수정에는 이미지 생성 모델을 사용하지 않았습니다.

## 파일

IDLE / HAPPY / THINKING / COOKING / SAD / LOVE 각 1장, 총 6장입니다. 파일 이름의 숫자는 이 순서를 뜻합니다. 모두 1254×1254, sRGB, 실제 투명 배경의 RGBA PNG입니다. 강제 확대 없이 원래 해상도를 유지했습니다.

## 수정 내용

- 공통: 기존 냉장고 얼굴을 필요한 만큼 세로 보정하고 눈·입·볼터치를 기준 좌표에 맞췄습니다. 모자는 기존 형태를 유지한 채 얼굴 접점과 함께 이동했습니다.
- IDLE: 중립 눈 크기와 기본 표정 배치를 정돈했습니다.
- HAPPY: 좁았던 눈 간격과 웃는 눈의 크기를 맞췄습니다. 왼쪽 장갑 자체를 축소하지 않고 몸 쪽으로 24px 옮긴 뒤 흰 소매 연결부만 압축해 길어 보이는 부분을 줄였습니다. 장갑이 얼굴 뒤로 겹치는 부분도 정리했습니다.
- THINKING: 눈 간격을 맞추고, 살짝 위·왼쪽을 보는 허용 범위 안에서 배치했습니다. 입은 짧은 선으로 줄였습니다. 기존 눈썹 하나와 생각하는 손동작을 유지했습니다.
- COOKING: 커졌던 타원 눈을 MASTER 크기로 줄이고 표정 위치를 맞췄습니다. 볼·거품기·잡는 장갑 형태를 유지했습니다.
- SAD: 얼굴의 세로 압축을 풀고 눈 크기·위치와 처진 입의 기준점을 맞췄습니다. 눈썹 두 개와 내려간 팔·모인 발을 유지했습니다.
- LOVE: 감은 눈을 줄여 기준 위치에 놓고 입·볼터치를 정렬했습니다. 하트와 안고 있는 장갑의 구조를 유지하고 캔버스 아래의 미세한 알파 잔상을 제거했습니다.
- 색과 선: 부위별 민트, 아이보리, 볼터치, 노랑을 MASTER 팔레트 기준으로 보정했습니다. 검게 강해진 구조선을 짙은 차콜로 정리하고 표정은 검정 계열로 유지했습니다. 기존 퀼팅·옅은 명암·곡선 형태는 재사용했습니다.

## 확인 결과

- 얼굴 가로세로 비율: 6종 모두 약 1.287–1.290:1. BIBLE의 기준 1.28:1 ±2% 안에 들어옵니다.
- 눈 중심 간격: 얼굴 폭의 약 38.75–38.86%. 기준 38.8%, 허용 37.6–40.0% 안에 들어옵니다.
- 일반 타원 눈 폭: 약 10.21–10.33%W. HAPPY·LOVE의 감은 눈 폭: 약 11.41–11.51%W. 눈 높이와 눈·입 위치도 감정별 BIBLE 범위를 확인했습니다.
- 민트 대표색: 밴드 #66C6A3, 손잡이 #68C3A1, 장갑 #65C3A0, 포켓 #65C5A2, 신발 #65C4A1을 기준으로 보정했습니다. 보정 후 각 재질 내부의 대표색을 다시 측정했으며, 목표와 RGB 채널당 최대 1단계 차이입니다. 그림자·퀼팅·하이라이트까지 한 색으로 채운 것은 아닙니다.
- 확대 상태에서 얼굴을 옮긴 자리, 파인애플 장식, 소매 연결부를 확인했습니다. 밝은 배경·어두운 배경과 전신 64px·128px 축소에서도 확인했습니다.
- PNG 6개의 알파 채널과 네 변의 완전 투명 여백, 전신·소품의 잘림 여부를 확인했습니다.
- 원본 캐릭터 이미지 57개와 v1·v2 PNG 각 6개는 해시 비교로 변경되지 않았음을 확인했습니다.

비율 수치는 회전된 래스터 윤곽을 측정한 근삿값으로, 벡터 설계도의 좌표를 뜻하지 않습니다. manifest.json에 파일 해시, 실제 측정값, 팔레트 확인 결과와 주요 편집 수치를 넣었습니다.

미리보기 시트의 배경과 포즈 이름은 확인용입니다. 개별 PNG에는 배경·문자·라벨이 들어 있지 않습니다.
