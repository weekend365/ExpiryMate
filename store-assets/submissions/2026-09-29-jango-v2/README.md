# 장고 v2 스토어 검토 묶음 · 2026-09-29

기존 제출본을 보존한 새 디자인 검토 후보입니다. 업로드하지 않았습니다.

- `graphics/`: `store:sync`가 생성한 Play 피처 그래픽과 App Store 세로 캠페인 이미지입니다. 캠페인 이미지는 iPhone 화면 캡처가 아닙니다.
- `manifest.json`: 그래픽 파일의 해시, 소스 커밋과 작업 트리 변경 여부입니다.

새로 촬영했던 Android 스크린샷 6장은 사용자 요청으로 롤백해 이 묶음에서 제외했습니다.
기존 `output/marketing/`의 제출 스크린샷을 유지합니다. 새 캡처는 gitignored 로컬 QA 기록으로만 보존합니다.
iOS 실제 화면은 Xcode 라이선스 미동의로 촬영하지 못했습니다. Android 화면을 iPhone 캡처로 재사용하지 않았습니다.
